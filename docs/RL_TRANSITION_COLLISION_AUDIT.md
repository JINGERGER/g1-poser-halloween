# 站立转爬行：碰撞与验收条件审计

2026-10-26 后续：`RL_TRANSITION_SURFACES_AND_HANDOFF.md` 已完成右侧原始三角面核查：七个未决姿态均找到打印壳体与右髋滚转部件表面交叉。另完成五个低姿态接管点的配对试验，四个不满足原ready的状态仍可接管成功；不等于站转爬完成。

## 范围与结果

本轮不追加训练、不修改冻结模型、不放宽现有验收条件。
对 event PPO 最终策略的八条严格评估轨迹，重建其最后一个失败姿态（0.170–0.172s）。
来源：`output/rl/closed_loop_transition/2026-10-23_16-27-00-393302/report.json`。
报告：`output/rl/transition_collision_audit/2026-10-23_18-31-18-576249/report.json`。

发现大腿碰撞胶囊挂在 hip_roll body 上，而它覆盖区域内还有随 hip_yaw 关节运动的外形。
因此不能把这根胶囊与真实大腿外形等同，也不能只对比 hip_roll 一个网格。

本轮比较同侧前臂打印壳凸包与 hip_pitch、hip_roll、hip_yaw、knee 四个可视网格。
使用编译后的 mesh 顶点及 geom 世界变换，线性规划寻找分离平面；对全部顶点重新计算投影间隙。
正间隙证明两个完整凸包分离，也证明它们包含的三角网格分离；不能找到分离平面则结论不确定，不能证明凹形实体发生干涉。

- 左侧：八个失败姿态中，前臂与四个网格都存在分离平面。最接近的 hip_yaw 网格间隙下界为 **0.918–1.915mm**，hip_roll 为 **5.992–7.694mm**。
- 这支持：在这些姿态、这些文件外形范围内，左前臂—大腿胶囊接触不是对应网格之间的实际接触。
- 右侧：七个姿态至少一个比较未能证明分离；仅一个姿态四项都分离，最小下界 **0.253mm**。不能据此宣布右侧也是假碰撞。
- 零间隙输出表示“未获得分离证据”，不是测得零距离或真实穿透深度。

这不是全机器人碰撞核查：未覆盖手球、跨侧部件及完整连续轨迹。可视网格也不是实机测量，毫米级间隙不足以证明硬件安全。
本轮仅重建几何，不使用重建后的接触力作动态结论。原轨迹的穿透和失败事实仍保留。

## 验收阈值的性质

来源：`rl/near_handoff_task.py` 的 `measure()`、`finish()`，及 `rl/stand_transition_task.py` 的 `measure()`、`ready()`。

| 条件 | 当前用途 | 审计结论 |
| --- | --- | --- |
| XML joint actuator force range | 仿真实际力矩限幅 | 模型硬约束；不等于电机热容量或实机持续输出证明 |
| 力矩比例 <95% | 每2ms严格终止 | 人工安全余量，不是实际100%限幅；不能把触及95%直接说成电机不够力 |
| 自碰撞穿深 ≤1mm；全部穿深 ≤5mm | 每2ms严格终止 | 几何与软接触数值容差；要结合代理外形和求解参数判断 |
| 非指定支撑部位触地法向载荷 ≤1N | 每2ms严格终止 | 指定动作形式的约束，不是物理不可实现判据；打印前臂与手球按 geom 分开分类 |
| 关节超限 ≤0.001rad | 每2ms严格终止 | 模型关节范围加数值容差；模型限位是软约束，并非角度绝不会越界 |
| 转换时骨盆高度 0.16–0.95m | 每2ms严格终止 | 任务筛选范围，不是通用物理边界 |
| 连续51帧四点各 >5N，骨盆 ≤0.4m | 允许 handoff | 初始启发式：51个2ms采样跨100ms；不是已测得的控制器吸引域 |
| base六维速度范数 <0.5 | 允许 handoff | 混合 m/s 与 rad/s，缺少尺度归一化；不能解释为“速度低于0.5m/s” |
| 与爬行名义关节角 RMS <0.35rad | 允许 handoff | 姿态启发式，既未证明必要也未证明充分 |
| handoff后连续2s、合格步态周期、前进 ≥6cm、全程严格通过 | 成功判定 | 当前任务的功能验收；保留，不能用局部接触时长或恢复后成功替代 |

因此，历史严格成功率仍为0/24，但其含义是“不满足当前验收”，不是“站转爬物理不可行”。
训练中允许恢复的接触时长也不能改写这一结论。

## 下一步决策

1. 只针对右侧未决的 hip_roll/hip_yaw 与打印壳体做真实三角面/原始CAD核查，随后结束本轮局部几何追查；不无限扩大扫描。
2. 如确需新腿部碰撞模型，按刚体分配外形并建立独立候选资产，保持质量、惯量、执行器不变；先回归站立与冻结爬行，禁止直接覆盖原模型或删除自碰撞。
3. handoff验证单独做反事实分支试验：从已保存状态分别测试直接接管与继续过渡，记录速度、姿态及接触，估计成功区域。分支实验不是连续站转爬成功。
4. 几何基线确定后再比较“张臂准备—双臂着地—吸收动量—接管”的接触事件策略与直接训练。允许脚移动和双臂不同步微调，不追求强制对称。限制实验预算，按失败类型决定下一步。
