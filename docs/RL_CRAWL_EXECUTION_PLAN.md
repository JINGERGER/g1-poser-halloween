## 总体验收与里程碑

1. **抬肢和回载**：实际接触力卸载、接触点离地≥10mm并连续80ms、随后回载；分别验证四肢。
2. **短步**：实际空中前移、落在目标附近并恢复承重；不能通过拖地和回放qpos伪造。
3. **连续爬行**：四肢在同一不重置的原生动力学episode内交替迈步，至少两个完整周期，
   躯干净前进≥6cm；不是仅手移动、机身静止。反复评估记录每肢实际接触、间隙、位移与载荷。
4. **重复与边界**：至少三个从头reset的名义物理rollout通过，并另列扰动/参数敏感性结果。
   名义重复不叫泛化成功率；硬件可部署需要额外实物校准，不由本项目的仿真成功推导。

运动只能由模型内电机和接触产生；禁止中途qpos投影、外加扶持力、关掉碰撞或改质量伪造成功。
原严格短步验收继续独立保留。训练门槛、功能运动指标与硬件安全判据分开，不能把实验阈值
误当硬件定律，也不能放宽训练条件后宣称已经通过旧严格验收。

## 路线与停止条件

- **A：关闭短接触门槛分支**。先用已训练最终策略做反馈式反事实重放，只允许左壳体≤5N、
  连续≤80ms的短接触，其他条件不变；这是未校准的诊断条件，不是硬件许可。
  若没有卸载/离地事件，停止对该门槛单独继续投入训练；不反复试更大力或更长时间。
- **B：直接抬肢/落地目标**。现有纯减载奖励可能停在有载接触，应建立事件驱动的离地/回载
  目标与相应观测，而非只放大减载奖励。把它作为独立任务路线，保留旧模型和基线。
  首先查新奖励是否在保持、减载、拖动和真实抬肢之间排序正确，再做有限预算双种子训练。
- **C：全身动作与参考路线**。若B两次预定预算档位都未出现离地事件，比较任务空间/协调
  动作与关节残差，或可行运动参考引导；不对同一组权重持续微调。动作覆盖仍服从真实关节电机范围。
- **D：组合爬行**。只有四肢单独事件成立才连接完整周期；若组合破坏承重，训练过渡而不是
  宣称四个独立技能已经等于爬行。坡道和楼梯在平地周期之后。

每条新路线预先写预算、主要指标、对照与退出条件。根据事件进展而非回报选路线。
初始策略允许失败，不再以“训练前先稳定”无限推迟训练。
更长训练可以是一档预定实验，但不能成为缺少任务进展时的默认动作。
