# 原生接触平衡与带载过渡

## 本轮冻结设计

目的：消除前轮独立接触力变量与 MuJoCo 软接触响应的差异，不改模型或放宽5mm穿透验收。
使用前轮两个带载初态各自的四肢/三肢静力解作为唯一初始猜测，共四个问题，不重启搜索。
原 MuJoCo 3.8.0、原模型/PD/摩擦/限矩均保持不变，无 RL 更新。

- 决策变量改为29维基座/关节位形增量与23维实际伺服目标，不再独立优化接触力。
- 每次目标/约束计算都 mj_resetData，零速度、零外力，再 mj_forward。
  接触载荷、摩擦及执行器力均由原生求解器计算；清除 warmstart，避免有限差分受调用历史污染。
- 等式直接要求原生全系统 qacc 为零，独立验收基座线加速度范数≤0.01m/s²、
  其余广义加速度绝对值≤0.1rad/s²，不依赖优化器 success 标记。
- 原范围内允许基座与关节调整；支撑末端水平位置相对带载初态可移动≤3cm，
  这仅是候选姿态范围，能否实际移动仍须原状态过渡重放。
- 原生承重肢负载≥10N，避免前轮左手被压到5N下限；右脚几何净空≥2cm、载荷≤1N。
- 优化穿透上限4.5mm，给未改变的5mm重放门槛留0.5mm余量；非支撑几何不能穿地，
  禁止部位总载荷≤1N、力矩利用率≤95%、关节/目标角在原范围内。
- 每问题最多150迭代/90秒，总四问题。不追加迭代、不改变阈值挑结果。

数学验收通过才做3秒假设初始化保持；**保持通过才做原状态6秒带载过渡**。
过渡沿用前轮0.5秒等待、3秒平滑变化、目标变化≤0.01rad/20ms，未优化阶段时长。
重放安全、三肢持续支撑及峰值采样口径均复用已验证的 `contact_seed.replay`。
候选保持不是可达性证明；过渡若通过也不等于完整抬落/推进，更不是连续爬行。

两份三肢终点都没有右脚载荷，但这只是人为设置候选姿态后的静态计算，**不是从带载状态完成了卸载**。
初态1末端右脚净空达23.90cm，初态2为2.61cm；本轮只有2cm下限，并非精确追踪2cm抬脚轨迹。
这进一步说明不能把未收敛的最终候选当作运动示范。

三肢候选的实际接触载荷顺序为左手、右手、左脚、右脚：

- 初态1：`[96.32, 105.87, 106.15, 0] N`，最大力矩比例0.922；左右掌都超过5mm穿透。
- 初态2：`[11.97, 149.90, 145.96, 0] N`，最大力矩比例约0.950；右掌穿透7.082mm。

两者均达到迭代上限，且独立约束验收失败；不是仅仅优化器标志不理想，也没有数据支持“只差延长过渡时间”。
仍不能从这两个局部终点推出全局不可行、真实电机不足，或允许放宽接触门槛。

## 验证与路线决策

- 测试确认每次原生计算清除warmstart，先评估其他状态再返回原状态，结果逐位相同。
- 用独立MjData重新计算qacc，验证不是旧接触力缓存造成的平衡假象。
- 复算四组约束、来源哈希和预算，独立重放全部四段通过的四肢保持/过渡，qpos/qvel误差≤1e-9。
- 当前仍没有可用于RL的成功三肢示范；原有训练/模型不变。

本轮已消除“独立接触力可任意实现”的假设，下一步不继续重复相同的右后脚局部求解。
应把**起步肢体和支撑顺序**纳入整体路线：以相同预算与物理门槛比较四种单肢卸载候选，
明确可能需要不同的身体转移/支撑布局，而不是默认右后脚必须最先抬起。
这项矩阵尚未执行；其结果也不能单独代替完整四肢循环。
接触垫软硬参数与5mm门槛的实际含义仍需校准，未经证据不调整模型或门槛。

后续矩阵现已完成，详见 `docs/RL_SUPPORT_ORDER_MATRIX.md`：初态2的左脚离地候选通过原生平衡及3秒保持，
但从原带载状态的固定目标角插值仍失败。已找到有限的三肢承重证据，尚无成功卸载路径或完整爬行。
