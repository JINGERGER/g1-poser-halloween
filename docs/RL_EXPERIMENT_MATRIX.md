# 整体实验方案：改装 G1 四肢爬行

日期：2026-10-15。目标是得到可验收的物理控制器，不是追逐单项奖励或复现未知权重。

## 固定边界

- 使用现有 23 关节改装模型、质量/惯量、接触几何、自碰撞和力矩上限。
- 参考 `g1_crawl` commit `935e8b9c857bd494b952603c0453800a0cf5c9d2` 的学习任务，而非标准 G1 权重。
- 新建独立任务和入口，不加载旧 85/93 维策略，不改动原有 GUI、V1–V5 或 UniLab 源码。
- 先做完整接口验证，再比较整套学习方案；不再要求静态三点支撑或固定 PD 完美。

## 固定验收，不挑视频

- 每个 checkpoint 固定 100 个首回合测试，报告分布而不是最优回合。
- 指令跟踪、净前进、横向偏移、20 秒完成率分开报告；静止策略不算爬行。
- 四肢分别按真实碰撞几何间隙、无接触、卸载，再重新承重识别成对步态事件。
- 躯干/非末端承重、接触点滑移、穿透、持续力矩饱和用原生 MuJoCo 重放核实。
- 固定首回合视频和测试 seed，不按观感筛选视频；多 seed 均报告，包括失败。
- 具体物理阈值在阶段 1 前锁定到评估配置；训练 reward 不用作成功标签。

## 已发现的参考与本机差异

1. 参考 `reset_from_animation_frame` 在抽取 frame_indices 后结束，没有状态写回。
   因而“源码配置使用随机动画帧”不等于实现真正生效。我们实现其意图，明确不是逐行复现。
2. 本地 UniLab MLX runner 将全部观测 concatenate 后喂给同输入维度的 actor/critic。
   仅改 YAML 的 obs_groups 无法实现非对称观测。必须显式切片并测试 actor 不依赖 critic 数据。
3. 参考训练 USD 仍是 LFS 指针；播放 XML 不能证明训练碰撞/惯量一致。
4. 接触历史、Isaac 隐式执行器、自碰撞开关与 MuJoCo 不完全等价。
5. 参考 symmetry augmentation/mirror loss 和物理随机化不能通过写入未使用的 YAML 假装开启。
   阶段 0 可关闭以验证链路；阶段 1 前明确实现或冻结为 A/B 共同的、具名的简化基线。
6. 动画只作 reset 来源，不预设四肢相位、不提供 imitation reward；其物理可行性不由动画文件保证。
7. 发现本机 UniLab 的 ELU 在大正值上计算未选中的 exp 分支，反向传播可产生非有限梯度。
   本仓库使用相同 ELU 数学函数的有限指数实现，不改 UniLab、不裁剪观测、不调奖励掩盖问题。
8. 显式设置每 minibatch 的 KL 统计和自适应学习率更新，避免默认 metrics_interval=8 与
   update_interval=5 在每轮 20 个 minibatch 下不触发更新。保留逐 minibatch 有限值检查。

## 失败分支与停止规则

- 接口、坐标、终止或重置错误：修复后重跑阶段 0，不调整奖励掩盖问题。
- 两个 PD、两个 seed 的足量预算都只支撑/滑动：停止盲目延长，转物理可行参考轨迹 + RL tracking。
- 单 seed 成功：检查探索/随机化稳定性，不宣布成功，不只保留好结果。
- 有步态但跟踪差：只针对已测出的瓶颈做一个模块消融，保持其余条件一致。
- 坡道或楼梯失败：先检查碰撞和任务观测，再考虑地形课程；不同时改模型、奖励、网络和控制。

1. 冻结本轮失败基线。设计统一固定时域/吸收失败状态等终止语义，先用反例测试确认提前失败
   不会仅因少承担后续成本而占优；如保留提前 reset，明确终止价值与超时 bootstrap 的区别。
   物理安全检查保留，不能把诊断中禁用终止的方式直接当作训练修复。
2. 用现有 80 帧动画作为候选姿态序列，不假定为可执行专家数据。按名称映射后检查时序、
   根姿态连续性、接触切换、当前限位与速度，再用真实 PD/力矩限制连续模拟；不得每帧强写 qpos。
3. 候选参考若不可执行，先用接触约束的轨迹生成/优化获得短程动作；禁止直接拟合不可实现动画。
   若可执行，才做带参考相位/目标观测的 RL 跟踪短跑；这是具名的新任务，不悄悄更改本轮无相位基线。
4. 跟踪任务先验收支撑转移和四肢真实抬落，再以同一物理门槛做前进验收；小预算双种子均无进展则停。
   在实施前单独冻结预算、动作参考来源、失败语义和评估协议，不自动再跑一轮 1200 万。
5. 平地通过后才增加地形相对高度、全地形接触检测和坡度课程，最后分开验收上楼/下楼。
