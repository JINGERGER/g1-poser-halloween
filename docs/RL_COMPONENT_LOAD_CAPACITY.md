# 固定姿态的四种卸载静态受力筛选

## 协议与近似

固定新碰撞候选中通过3秒保持的初始化平衡姿态，不改变姿态、支撑位置或模型参数。
执行1次四支撑可行性检查和4次目标肢体载荷最小化，每次LP上限20秒/10000迭代，0姿态搜索。

实现：`rl/component_load_capacity.py`；复核：`rl/check_component_load_capacity.py`。
报告：`output/rl/component_load_capacity/2026-10-19_20-30-21-385565/report.json`。

变量为各接触点的世界系三维力及23个关节力矩，满足：

```text
J_contact.T * force + actuator_torque = qfrc_bias - qfrc_passive
fz >= 0
abs(fx) + abs(fy) <= mu * fz
非目标肢体总法向载荷 >= 5N
当前姿态的可实现电机力矩下限 <= torque <= 上限
```

浮动基座6维和关节23维平衡一起求解，不以单关节力矩比例替代整体能力。
电机力矩区间同时考虑当前位置、ctrl范围、仿射位置伺服、执行器/关节限矩；不借助静摩擦助力。
摩擦采用圆锥内接菱形，较真实圆锥保守；不提供接触点力矩。

**该姿态实际生成4个地面接触点，每个肢体1点，包括每只脚也只有1点。**
本轮固定这些点，不把完整足底多边形当作已可用接触区域。
因此结果只对应这个接触点模型，尤其不能由脚的非零载荷下界推断整个足底接触下仍不可卸载。

## 结果

四支撑基线受力可行。分别最小化每个肢体载荷：

| 目标 | 最小法向载荷 | 能否到零 |
| --- | ---: | --- |
| 左手 | 0.000N | 能，在当前理想化LP中 |
| 右手 | 7.780N | 本近似下不能 |
| 左脚 | 2.986N | 本近似下不能；低于5N不等于完全卸载 |
| 右脚 | 70.775N | 本近似下不能 |

左手为零的解，右手/左脚/右脚载荷约143.74/101.32/67.09N。
载荷合计约312.14N，与模型重力匹配。独立世界系总力和绕COM总力矩复查通过。

所有5个LP的“求解成功”只表示优化正常完成；不意味着4种目标都能卸载到零。
左手零载荷解的最小电机力矩区间裕量为0，至少一个关节在可实现区间边界。
最小载荷目标可能返回退化的边界解，这不证明所有左手零载荷解都无裕量；也不能忽略这一点直接执行。

## 如何使用，不能如何使用

- 左手可以作为下一项的**优先静态候选**，不再没有依据地固定左脚优先。
- “左手零载荷”不是离地，未证明软接触可实现该载荷分配，更未证明电机能动态到达。
- 其他三项的非零下界限于当前姿态、当前4点与保守摩擦模型，不是机器人全局不可行结论。
- 本轮理想化静态计算不解决上一轮接触时间常数+20%时7.108mm穿入的问题；鲁棒性失败仍保留。
- 未生成RL成功样本，未执行卸载或抬肢轨迹。

## 下一项：先检查裕量，不直接命令LP极值解

固定左手载荷为零，在同一姿态/接触点模型中求最大化执行器与摩擦裕量的解。
若有内部可行解，再把力矩换算为受限ctrl，并做有预算的原生软接触一致性检查；
若没有，报告最紧约束，并区分接触点近似保守与真正的执行器限制，不靠放宽限矩制造成功。
之后才选择身体移重与接触切换路径。静态支持区域与原生接触分配必须分开验证。
