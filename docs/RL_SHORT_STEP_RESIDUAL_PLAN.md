# 完整短步残差RL：冻结协议与有限预算

## 目标与边界

停止继续优化同一个三支撑静态终点，直接建立完整短步训练闭环。
第一任务是左手向世界+x方向前移3cm并重新承重，不是机器人完整周期爬行。
不要求传统控制器先完美，但不把IK或已有减载轨迹当作成功步态。

阶段A：任务、事件判据、冻结资产、基线评估、接口测试。
阶段B：MLX PPO smoke，固定4环境×24步×4更新=384次transition。
阶段C：另行显式启动screen，每种子8环境×24步×64更新=12288次transition，仅种子1、2。
本轮只执行A/B，不自动启动C，也不根据结果不断增加预算。

## 冻结环境

- 模型：`component_hulls_v1_12d607bfdb588900`，20mm手球，分部件凸包。
- Reset：新模型已通过3秒电机保持的完整物理初态。只在episode边界重置，不投影地面、不重置到IK中间帧。
- 仿真2ms、控制20ms、单任务4秒。每个物理步检查原5mm穿入、非支撑载荷、其余三支撑、电机与关节范围；另检查超过1mm的启用自碰撞。
- 不修改应用默认模型、旧快照或UniLab源码。暂不随机化质量、摩擦和初态；这是名义环境，不是鲁棒性训练。
- 接触时间常数+20%的失败、邻接凸包过滤、惯量覆盖不确定性继续保留。

## IK与残差控制

`rl/short_step_assets.py`生成内容哈希命名的bundle，记录模型、mesh、初始报告与协议哈希。
只在准备阶段生成参考，不在step/reset中解析资产。
IK固定机身，跟踪四个接触geom中心，左手按离地2cm、前摆3cm、落地轨迹运动；关节范围来自冻结模型。
IK关节偏移加入原带载ctrl作为名义目标，策略输出23维残差，范围±0.25rad，
最终目标受ctrl范围及每20ms最多0.01rad变化约束。允许策略偏离IK，IK不被标注为动力学可行。

时间参考：0–0.8s准备；0.8–1.4s抬手；1.4–2.0s前摆；2.0–2.6s落地；2.6–4s重新承重。
事件判据不依赖策略是否按参考时间表执行，只依赖实际接触、位置与速度。

## 成功判据（全部按顺序满足）

1. 左手载荷≤1N。
2. 左手实际地面间隙≥10mm且载荷≤1N，连续80ms。
3. 在离地至少5mm时，相对初始位置及确认离地时的位置均向前移动≥20mm，防止先拖动再原地抬手。
4. 落地位置距3cm目标水平误差≤15mm，左手载荷>5N，四肢接触，间隙≤2mm。
5. 连续300ms满足落地条件，广义速度最大绝对值≤0.05，载荷加权滑移≤0.02m/s。

整个episode须无守卫失败。只是减载、原地抬手、滑着前推、落地后持续运动都不算成功。
该成功定义仍是单手步，不要求躯干净前进，不能直接称为成功爬行。

所有轨迹都没有速率限制；0.003rad组的4条轨迹发生过目标范围裁剪，

结论：在这些名义样本中，协调参考附近存在可承受小幅平滑扰动的轨迹，
不是仅能执行一条完全无噪声的轨迹；小幅平滑零残差也能进入抬手时间窗，
但没有协调参考时不能跑满任务时长。尚未证明邻域足以探索到真正离地或完整短步。
不把8/8当作泛化成功率，不把4秒安全保持当作任务成功，也不继续搜更大扰动幅值。
