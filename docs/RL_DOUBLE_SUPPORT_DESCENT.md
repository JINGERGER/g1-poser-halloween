日期：2026-10-29。此实验不替换 Halloween 场景或冻结爬行策略，不运行 RL 训练，不宣称已完成站立转爬行。

2026-10-30 更新：该连续末态之后已验证双臂从头顶移到前下方约 60cm 的准备动作；路线审查不再只围绕增加下降量，详见 `RL_TRANSITION_ROUTE_REVIEW.md`。双手落地和爬行接管仍未完成。

## 问题与方法

已验证右→左移步、扩大站姿的连续轨迹：
`output/rl/predictive_step_chain/2026-10-29_11-06-00-449154/report.json`。

下一步先回答：扩大站姿以后，能否在双脚不移位、持续承重的条件下，让机身和重心一起降低？不直接把手移到地面，也不以手臂上举或一次高度采样替代完成验收。

- 前段从真站姿开始，逐个积分归档的 2ms 控制输入，并比较所有 qpos/qvel；不直接加载成功末态。前段是名义条件下的归档控制重放，不能据此声称具有扰动鲁棒性。
- 下降参考在实际当前状态上规划，使用完整自由根位姿和 23 个关节，不强制镜像姿态。规划只操作 scratch data，并比较真实 integration state 没有改变。
- 初始目标为机身和 COM 同时下降 3cm，水平 COM 位置和脚位/朝向保持。双手参考随高度一起下降，暂不要求接地。
- 静态筛查使用内缩 5mm 的脚底角点、非负竖直支撑力和 70% 静态关节力矩上限。仅作规划筛查，不能代替物理积分。
- 延续原生位置 PD、20ms 物理预测与非线性候选代价复核。下降参考名义持续 8s，随后保持 4s；双脚承重不足时暂停参考推进，总预算 16s。超时不是成功。

## 验收

1. 沿用原逐 2ms 总穿深、自碰撞、实际力矩、关节限位、非支撑接触和机身高度门槛，不修改质量、惯量、摩擦、碰撞或硬件限力。
2. 下降阶段所有样本双脚各承重超过 20N，最终至少一秒持续承重；脚位漂移小于 5mm，方向保持。
3. 机身高度和 COM 高度的实际下降量均在目标 ±5mm 内，水平 COM 漂移小于 1cm；完成参考后保持 4s，最终线速度小于 0.05m/s、角速度小于 0.1rad/s。
4. 整段从真站姿开始再次逐步积分。独立检查前段控制和状态与原归档一致，重新测量全部物理门槛、载荷与穿深，同时核验轨迹及归档代码哈希。

## 已完成结果

报告：`output/rl/predictive_descent/2026-10-29_11-17-06-279260/report.json`。

- 整段连续仿真 58.96s，其中扩大站姿前段 46.96s，下降与稳定保持 12s；共 29,480 个物理步，下降段 600 次控制更新。
- 31/31 参考节点通过几何/静态筛查；目标下降 3cm，机身实际下降 **2.846cm**，COM 实际下降 **2.816cm**，不能写成精确下降 3cm。
- 下降阶段左/右脚最低载荷分别 **148.10/154.76N**，全程双脚持续承重；最终脚位漂移分别 **0.0932/0.0935mm**。
- 整段最大总穿深及自碰撞穿深均 **0.465mm**；实际力矩比例峰值约 **0.8003**，低于原 0.95 物理门槛。
- 机身高度从扩大站姿后的 0.72375m 降到 0.69528m；最终线速度约 `5.97e-7 m/s`，角速度约 `1.10e-6 rad/s`。
- 下降控制预测末端速度与实际末端速度最大误差为零；独立审计从真站姿逐个重放全段控制并重新计算物理门槛，**通过**。

这验证的是**一个名义初始条件下，连续移步以后的小幅双脚承重下降**。前段为已验证控制序列的物理重放，后段为在线预测控制；尚未验证更深下降、双手承重切换、扰动鲁棒性或冻结爬行接管。

本次首次运行耗时约数分钟到十分钟，不能与 58.96s 仿真时长混淆；旧报告没有分阶段墙钟计时，不能把时间归因于某个求解器。下降段没有数值重试，600 次 QP 累计 53,875 次迭代、单次最多 700 次。后续入口已增加前段重放、规划、控制和最终重放的独立计时与进度输出，便于定位计算成本。

下一步不是直接将这 3cm 的结果外推到落手：先检查更低姿态所需的踝/膝活动空间和静态力矩余量，再从同一连续状态推进下降及手臂准备；保持双脚承重与真正切换到双手承重应分别验收。
