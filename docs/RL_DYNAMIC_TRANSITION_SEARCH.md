# 固定预算的站立起点动力学搜索

日期：2026-10-23。承接`RL_FULL_TRANSITION_ROUTES.md`，本轮真正以连续MuJoCo结果选择动作，
不是继续筛IK节点，也不是扩大低位接管样例。

## 运行前固定的设计

实现：`rl/search_dynamic_transition.py`。独立测试：`rl/check_dynamic_transition_search.py`。
报告在执行前写入预算、评分、资产哈希和验证初态。

- 2类初始化 × 2个随机种子（7、11）× 4代 × 每代12个候选 = **192条搜索轨迹**。
- 每组只选一个搜索候选，再分别以初始vx±0.03m/s、vy±0.03m/s验证，共**16条扰动验证**。
- 搜索全部从真实站立、零初速度开始，不从低位重置；验证状态不参与搜索或参数选择。
- 动作为3个23关节关键点和总持续时间，共70维；持续时间0.6–3秒，关键点间平滑插值。
- 参考初始化来自先前倾IK路线，初始标准差0.35rad；宽范围初始化来自站立到爬行端点的线性中心，标准差0.9rad。
- 每代保留均值候选和2个从原始分布重新抽取的候选，另以4个精英更新分布；设置标准差下限防止立即收缩。
- 两种分布都可改变左右关节，不锁定严格对称。它们并未覆盖全部动作空间，更不是两种独立控制架构。
- 原生PD、力矩限制、自碰撞、非支撑接触和每2ms物理检查保持原样；动态期间没有基座覆盖或外力。
- 满足既有接管条件才连续调用冻结爬行，并验证后续2秒步态；全部208条保存控制并重放检查。

评分按优先级排序：完整成功、双手持续承重100ms、双手持续时间、任一手持续时间，最后才用手距地面的有效前缀进展打破平局。
首个物理失败采样不计入接触/进展评分；单纯降身或活得久没有奖励。
但失败轨迹的有效前缀仍可进入精英，这只是搜索引导，**并不让它成为合格动作**。
当没有持续支撑时，搜索仍可能沿着“更接近地面但接不住”的方向选择；报告明确保留这一限制。

这里只能比较这两种提议分布在当前小预算下的结果，不能断言所有参考方法都优于无参考方法。

## 最有进展候选为何仍不合格

参考/11入选候选在约1.144秒终止：指定左右手球同时有接触，
但`right_forearm`（打印壳体凸包）也产生约63.5N接地力，因此触发非支撑接触门槛。
接触分类依据geom，不是body：手球与打印壳体同属`right_wrist_roll_rubber_hand`，
不能因为body名字有hand就把整个壳体接触当成允许的手球支撑。

终止时骨盆横向位置约−0.566m，横向速度约−1.718m/s、下落速度约−1.332m/s，
仍有明显转动速度。它不是稳定双臂接住身体，不能因为手曾承重就作为成功演示。
95%力矩门槛和禁止壳体承重是当前验收约束；触发它们不等同于证明真实电机无法完成动作。
本轮不删除壳体碰撞、不放宽承重白名单、不修改力矩门槛来制造成功。

## 路线级决策：停止扩展这一轮开环搜索

按预算结束，不继续追着84ms候选微调，也不把它作为成功示范教给策略。
本轮是时间相关的开环关键点搜索，不是闭环RL。它证明在当前预算/表示/约束下没有得到成功轨迹，
不能证明不存在可行动态轨迹，也不能证明闭环RL一定能解决。

下一阶段需要改变控制表示而不是只扩大同一搜索：

1. 面向完整任务的闭环控制，观测身体姿态/速度、两手两脚接触、关节状态和当前目标；动作在一段时间内相关，避免小噪声积分或独立大噪声关键点这两个极端。
2. 将“主动前倾—落臂—吸收动量—接管”作为事件阶段，不要求按固定时钟完成；保持可以调整脚部和左右差异的自由度。
3. 参考路线只作探索偏好/对照，不强制跟踪无法动态实现的基座曲线。当前失败片段用于诊断，不当成功动作标签。
4. 对照有参考与无参考闭环学习，按有效接触覆盖率、失败类别和真正接管成功率判断，不把更低的身体位置或更长的单手接触当终点。
5. 如果需要修改壳体接触规则，必须作为独立建模/任务定义决策，先明确硬件允许性，再重新报告基线；不能隐藏在训练调参里。

以上是下一阶段方案，尚未实施或训练。当前可运行的冻结爬行控制器未修改，完整站立过渡仍未完成。
