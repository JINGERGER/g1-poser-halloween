# 改装 G1：可重复平地物理爬行

2026-10-22。此页是当前运行入口与验收摘要，早期失败记录保留不覆盖。

## 已实现与边界

23执行器改装模型在原生MuJoCo动力学中实现连续对角交替爬行。
三次独立初始化的10秒名义运行均前移4.806m，各有22个合格完整周期，
包含至少两个连续合格周期；另做1ms物理步长及初始偏航±0.03rad检查，均通过。
这些是确定性名义重复和有限敏感性检查，不是随机扰动成功率或真机验证。

这是上游已训练RL策略加确定性的踝目标限制、腿部任务空间残差，
不是本机从零训练出来的新PPO策略，也不是回放qpos。策略每20ms读取当前物理状态。
原单手固定目标/静止保持任务没有被改判成功；连续爬行不宣称通过那个独立任务。
坡道、楼梯、任意速度/转向、长期耐久运行和真机部署不在本次平地验收范围内。

## 启动

在当前Mac环境运行10秒实时物理可视化（macOS使用mjpython）：

```bash
cd g1-poser-halloween
uv sync --extra crawl --python 3.13 --locked
uv run --extra crawl python rl/install_crawl_assets.py
uv run --extra crawl mjpython rl/run_crawl_controller.py --viewer
```

默认使用万圣节草坪墓地：暗绿色草坪、两侧草丛、多排墓碑、阴天背景、幽灵和石台上的南瓜灯。
行进通道保持空旷；草丛和墓碑均为无质量、无碰撞装饰，不模拟柔软草地物理。
三位尖帽巫婆骑扫把在墓地两侧上空循环飞行、上下浮动并随路径转向。
动画按仿真时间更新独立装饰mocap，不修改机器人状态或施加外力；普通背景不加载巫婆。
万圣节视角稍微拉远并上移，兼顾地面机器人和空中的巫婆。
可显式传 `--scene halloween`；`--scene plain` 恢复原始背景。
万圣节装饰无碰撞、无质量，保留原地面碰撞参数；不导入斜坡，避免将平地验证误当爬坡能力。
派生场景保存在本次输出目录，不修改已验收的模型或原万圣节场景。
`rl/check_crawl_scene.py` 检查原物理参数不变以及10秒配对动力学逐控制点完全一致。

不打开窗口：

```bash
uv run --extra crawl python -B rl/run_crawl_controller.py
```

每次保存独立的 `output/rl/crawl_controller/<时间>/report.json` 和 `trajectory.npz`。
无窗口入口已实测，轨迹SHA256与三次名义验证完全相同。
可视化代码执行同一个闭环物理runner，仅额外同步摄像机和实时节奏；尚未人工验看窗口。
不要在viewer中拖拽施加外力；runner禁止外力辅助。窗口关闭会记录viewer_closed，
不能把用户提前结束的运行当作完整10秒验收。

## 冻结的运行配置

- 模型：`output/rl/models/component_hulls_v1_12d607bfdb588900/flat.xml`，23执行器，31.819kg。
- 保留打印件碰撞、质量惯量、摩擦、关节范围、电机限力；不关闭碰撞，不加扶持力。
- 参考策略来自固定提交 `935e8b9c857bd494b952603c0453800a0cf5c9d2`；策略SHA256：
  `1616790c7a1f56146d8a7ed07c32e414e76a5599a0d420f3811200fd36d9b1c8`。
- 共有21关节采用参考模型PD乘上游部署系数1.4；两腕仍为当前模型40/3，实际参与观测和控制。
- 接触solref时间常数显式设为0.005，物理步长0.002，策略周期0.02秒，前向指令0.5m/s。
- 两踝俯仰控制目标下限-0.2rad，不修改物理关节范围。
- 对侧手实际离地触发脚部任务空间抬升修正，经当前腿部Jacobian转换，各关节修正不超过0.2rad。
- 抬升修正请求值0.08m **不等于实际离地8cm**；本次脚部最高间隙约3cm，手约4cm。

原生PD与原solref=0.02配置的失败保留在对照报告中，不追认原配置通过。
0.005是有步长敏感性证据的仿真数值配置，不是实物橡胶/地面接触标定。
冲击载荷、硬件热限制、传动间隙等仍需独立验证。

## 验收不是只看机器人前移

1. 用保存ctrl重新执行原生物理，每个控制点qpos/qvel与闭环轨迹匹配至1e-10。
2. 每个1/2ms物理子步检查非支撑触地≤1N、总穿透≤5mm、自碰撞深度≤1mm、
   力矩比<0.95、关节限位容差1mrad和基座高度0.16–0.65m；另查初始化穿透。
3. 独立从逐子步载荷/间隙/足端位置重建事件：真实无载空中前进≥2cm，
   ≥10mm间隙连续至少80ms，随后载荷>5N连续40ms。不是把拖地计为空中移动。
4. 每周期四肢各有合格事件，左手/右脚与右手/左脚两组相位交替，
   至少两个相邻完整周期，躯干净前移≥6cm；同时整段10秒的物理门槛均通过。
5. 三次名义从头运行分别验收；步长减半及±0.03rad初始偏航另列，不混作泛化成功率。

名义结果：四肢合格步次25/25/24/24，22个合格完整周期；最大电机限力比约0.694，
无非支撑部位触地，无自碰撞，包含初始化的最大穿透约4.9005mm，无关节越界。
初始化已接近5mm边界，因此不能推断更大初始状态扰动同样安全。

早期 `crawl_verification.json` 因把亚毫米接触抖动也当作独立迈步而拒绝所有周期。
修正版保留所有事件，但仅将达到10mm的离地作为步态候选，仍逐步要求原80ms/2cm等条件；
不会把低于10mm的运动升格为合格步。`crawl_verification_v2.json` 是修正后的证据。
验证器包含对角交替正例，以及无前移、间隙不足、时长不足、同步跳动、相位错误、
微小弹跳、未回载反例测试。未修改动力学轨迹来配合验收。

## 路线记录

- 停止没有卸载事件的单手训练，保留失败报告，不持续追加同一奖励预算。
- 取回并校验上游策略，先复现参考模型，再迁移到实际23执行器模型。
- 对PD、姿态、策略周期、接触数值参数分别做有限对照。
- 定位脚—小腿碰撞与踝姿态的关系；限制踝目标，而不是删碰撞。
- 在安全踝目标下做两档有限抬升修正对照，随后冻结参数并独立重复验证。
