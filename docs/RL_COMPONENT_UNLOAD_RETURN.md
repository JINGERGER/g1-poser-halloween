# 25%动态减载：延长保持与平滑回撤

## 预先固定的三组试验

不改变25%幅度、原始初态、接触参数和安全门槛，也不重新优化控制方向。

| 分支 | 控制安排 | 最长时长 |
| --- | --- | ---: |
| 配对基线 | 原始保持ctrl不变 | 6s |
| 提前回撤 | 0–0.6s渐变减载，1–2s平滑回撤，2–4s保持原ctrl | 4s |
| 延长后回撤 | 0–0.6s渐变减载，3–4s平滑回撤，4–6s保持原ctrl | 6s |

三组在执行前一起写入报告；提前回撤不是长保持失败后临时追加的补救搜索。
沿用20ms控制周期、每次变化≤0.01rad、每2ms物理步检查所有既定守卫。
回撤阶段也不写qpos、不清零速度、不注入外力。

恢复条件：完整完成试验，最后0.5s每个样本都满足：
相对同时刻基线的各肢体载荷误差≤5N、水平COM误差≤5mm、广义速度最大绝对值≤0.05、
四肢接触且各载荷>5N、载荷加权滑移速度≤0.02m/s。
速度最大值是平移/转动混合筛选量，不冒充单一物理单位的速度。

实现：`rl/component_unload_return.py`；检查：`rl/check_component_unload_return.py`。
报告：`output/rl/component_unload_return/2026-10-19_20-50-12-737895/report.json`。

## 结果

### 基线6秒完成

未触发守卫，最深穿入4.935mm。基线用于同时刻比较，不将它与自身一致作为新的回撤成功证据。

### 1秒后回撤：通过本轮恢复检查

- 回撤前最后0.2s左手载荷较配对基线降低27.58%，复现上一轮结果。
- 完成全部4秒；最深穿入4.914mm。
- 末态四肢载荷约90.31/50.69/34.41/136.73N。
- 末态相对基线最大载荷差0.913N，水平COM误差1.488mm。
- 最后0.5s最大载荷差1.274N、最大COM误差1.787mm、最大广义速度绝对值0.00931。
- 最后0.5s最大载荷加权滑移速度约1.576mm/s。
- 控制回到原始ctrl，恢复条件通过；并非qpos精确回到原始姿态，也未证明无限期稳定。

这是一次连续的**减载—回撤—恢复四支撑载荷**，不是左手离地或爬行单步。

### 延长至3秒：在回撤开始前触发非指定接触

- 在3.000s停止，右前臂`right_forearm`地面载荷约**2.100N**，超过1N门槛。
- 当时左手仍承重约62.23N，右手/左脚/右脚约74.55/48.91/125.01N。
- 水平COM已相对初态移动约9.741mm，载荷加权滑移约7.876mm/s。
- 全段最深穿入4.914mm，没有触发5mm穿入门槛；这次失败不能归因于穿入超限或电机饱和。
- 计划回撤从3秒开始；控制首次真正下降需下一更新周期，但该分支已触发停止，因此**没有验证这个末态能否安全回撤**。

报告中的`pre_return_window_completed=true`仅表示取到了2.8–3.0s的统计窗口，
其中包含违规末点，不代表长保持通过。该窗口减载约31.73%，但试验结果仍为失败。
停止仿真也不是机器人已自主恢复安全状态。

## 当前判断

固定25%控制方向存在短时可恢复的载荷转移；但把同一ctrl持续施加会改变身体姿态并最终引入右前臂接触。
不能将1秒成功外推为稳定三支撑，更不能把前臂接触屏蔽掉后宣称长期通过。
这仍然是凸包碰撞候选模型内的结果，不是实物前臂必然碰地的测量证明。

本轮增加的是可恢复的动态减载证据，而不是完整卸载能力。
模型接触参数敏感性、质量/惯量装配范围、邻接凸包过滤等限制继续保留。

## 后续方向，不沿时长/幅度继续搜索

保留“1秒减载后回撤”为配对实验基线，不继续扫描1.2/1.5/2秒或0.3等幅度来挑最好结果。
下一阶段需要改变身体和支撑的运动路径，并显式考虑非支撑部件离地空间，
而非维持一个固定关节目标差并期待它最终卸载。
右前臂触地是必须保留的约束，不直接删除碰撞体、扩大排除或提高载荷门槛。
完整接触切换仍需包含受控移重、离地、摆动、落地和重新承重；当前回撤基线只覆盖其中的减载/恢复部分。
