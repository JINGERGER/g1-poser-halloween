# 站立到爬行：先验证端点，再训练过渡

## 范围与原则

冻结当前爬行策略和执行配置，单独学习过渡，不重训全部能力。
成功定义为从稳定站立连续执行过渡，并由现有爬行控制器接管完成完整步态周期。
不能仅以接近初始关节角判断成功；交接速度、接触、策略上一动作和控制突变都需要验证。
训练允许失败探索，但不允许中途覆盖qpos、清零速度或施加扶持力来制造成功。
本阶段不换框架、不训练坡道、不发布或改动已有版本标签。

## 顺序与决策门

1. **交接端点探测**：名义姿态、基座提高5mm、世界系前向速度±0.05m/s、
   向下速度0.05m/s、本体系俯仰角速度±0.1rad/s，共七个预先声明的独立案例。
   保持原20ms控制周期、2ms物理步长、接触/PD/踝/抬升配置和上一动作零初始化。
   每例做10秒闭环、逐子步物理重放和独立步态验收。失败全部保留，不现场追调参数。
   这只是有限单因素探测，不代表吸引域边界、组合扰动成功率或过渡可达性。
2. **站立端点**：在同一改装模型上构造并检查双脚承重站姿，验证电机保持。
   不把爬行home关键帧当站姿；记录站立PD配置，若与爬行配置不同必须显式设计交接。
   检查支撑、滑动、接触冲击、力矩、关节限位及手臂碰撞。没有稳定站立证据就不启动完整过渡训练。
3. **有限路线比较**：双手接地与单手先接地两条路线。IK只生成参考和检查可达性，
   动力学执行才是证据。膝盖支撑不是默认允许项，需要单独审计碰撞和受力假设。
4. **小规模过渡PPO**：从接近爬行末态起步，逐步向手接地、下蹲、完整站立扩展初始分布。
   动作为阶段参考姿态加有界残差；阶段推进结合实际接触，不单靠计时。
5. **端到端验收**：站立启动、无重置交接、持续爬行。固定评估种子及初态分布，
   同时报告成功和失败。时间混合、上一动作初始化都作为受测配置，不能假设平滑即安全。

## 交接诊断复现

在已安装crawl依赖和运行资产的仓库执行：

```bash
uv run --extra crawl python -B rl/check_crawl_handoff.py
```

输出位于`output/rl/crawl_handoff/<时间戳>/report.json`及每例轨迹/逐子步审计资产。
沿用既有爬行门槛：完成10秒、前移6cm、总穿透≤5mm、自碰撞穿透≤1mm、
非支撑触地≤1N、力矩比<0.95、关节限位容差1mrad、基座高度0.16–0.65m，
以及至少两个相邻完整对角周期。运行完成不等于所有案例通过，必须读取每例gates。

## 后续奖励与停止条件

- 奖励接近参考、合理接触建立、稳定负载转移；惩罚滑动、冲击和动作突变。
- 关键终端奖励来自冻结爬行控制器实际接管后的成功，而非单帧姿态误差。
- 站立任务的低高度终止不能照搬；低姿态是目标，但躯干撞地不是成功捷径。
- 若末态可接管而完整过渡失败，查接触路线；若末态小扰动就失败，先定位接管瓶颈。
- 若两条路线均缺乏物理可行证据，重新检查几何/承重，不无限增加同一奖励的训练预算。

## 连续执行接口（2026-10-23）

新增`rl/transition_execution.py`，作为后续过渡环境的执行核心，不是已训练策略或完整RL环境。
选择已有成功静态站立/短段降低的23关节位置伺服作为过渡接口；官方力矩策略保留为对照，
不会直接把它的力矩动作交给位置执行器。

- 过渡和爬行共用同一MjModel/MjData；交接不重置时间、qpos、qvel、内部物理状态或求解器warmstart。
- 过渡动作是按执行器顺序的23维位置目标，非法形状、NaN和超范围目标直接拒绝。
- 每次动作推进10个2ms子步；期间不允许外力扶持。
- `handoff()`显式改为冻结爬行参考PD，上一动作按已验证入口约定初始化为零，计算第一次动作。
- 首个爬行控制周期执行这次动作，不重复推理；之后保留上一动作历史，禁止重复交接清零历史。
- 交接前后记录PD、位置目标和同一物理状态下的瞬时广义执行器力矩差。
- 当前是显式瞬时切换，不声称平滑或安全；尚未加入接触/姿态就绪门槛、终端奖励和任务级终止条件。
- 禁止把官方腿部力矩执行器模型传入该位置目标接口；不会静默改变单位。

爬行动作生成提取到`rl/crawl_control.py`，原有运行入口调用同一实现，避免过渡接管代码另写一份策略逻辑。
每个新爬行运行报告附带controller源码哈希。已有Release标签未变更。

测试：

```bash

uv run --extra crawl --python 3.13 python -B rl/check_crawl_event_verifier.py
```

名义10秒轨迹SHA256仍为`686214684b7045787b53d8c7456deea3ba8c5503e28594d001b501c0b3274121`；
新接口从名义爬行初态接管后，500个控制周期的ctrl/qpos/qvel与该轨迹逐值相同。
另用原生PD站立实际执行2秒后的非零速度状态验证：handoff不改变物理状态和warmstart。
非法目标、重复交接、交接后再发过渡指令、力矩模型输入等反例均被拒绝；步态验证器回归通过。

**站立状态夹具只在交接处测量，没有继续执行爬行动作，不是成功过渡。**

用已验证短段降低作为参考，训练必须减少末态误差及交接突变，而不能通过重置末态来获得奖励。
