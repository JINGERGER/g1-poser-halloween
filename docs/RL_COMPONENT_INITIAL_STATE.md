# 新碰撞模型：四支撑初态与电机保持

## 本轮任务与预算

从两个固定种子出发：旧名义姿态、旧联合平衡姿态。旧状态只用作几何初猜，
不迁移其承重标签。模型为`component_hulls_v1_12d607bfdb588900`，手球半径20mm。

- 每种子：几何SLSQP最多100迭代/30秒，0重启。
- 几何目标：四个支撑间隙在-0.6至-0.4mm；关节限位、足底姿态、支撑平面位置和非指定接触受约束。
- 每个通过几何的种子：原生软接触联合平衡最多100迭代/60秒，0重启。
- 仅平衡通过后执行3秒电机保持；失败种子不做动态重放，不临时增加搜索。

实现：`rl/component_initial_state.py`。
报告：`output/rl/component_initial_state/2026-10-19_20-22-52-568702/report.json`。
报告在求解前保存协议，完成后记录两个种子的结果与失败状态。

## 可以证明什么

在该候选模型、固定接触参数及显式初始平衡状态下，存在四肢承重并由电机保持3秒的状态。
这是**新20mm球/分部件碰撞模型上的动态保持证据**，不再借用旧35mm球的结果。

不能证明：机器人能从任意启动姿态到达它、能卸载某条肢体、能迈步、周期爬行、上坡或上下楼。
初始化允许设置qpos/零速度，故仍称“初始化后的保持”，不是动态进入平衡的过渡。
它也不是硬件验证；邻接凸包过滤、质量/惯量覆盖和接触标定假设仍然存在。

最深穿入距5mm筛选上限仅约0.067mm，**通过但裕量很小**。
不能仅凭一次保持或62.57%的采样力矩比例断言整体承重能力充足。

## 下一步，不再盲调保持器

1. 冻结成功分支初态和控制，先做小规模接触/时间步敏感性复查，不为各变体重新调平衡来掩盖敏感性。
2. 以这一个新模型有效初态为入口，分别检查四种肢体卸载的整体力/力矩可行性，而非默认左脚优先。
3. 有依据后才尝试电机驱动的移重和完整接触切换；不把静态受力可行当成动态可达。

原计划的历史三个承重点仍只对旧模型有效，不为了凑齐12个单元虚构新模型初态。
本轮无训练，两个种子全部报告，无隐藏追加搜索。
