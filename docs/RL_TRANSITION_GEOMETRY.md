# 动态过渡前的支撑几何检查

## 本轮目的

先检查“已验证静态三肢终点”是否适合作为当前姿态的直接过渡目标，
避免把静态存在性误当动态可达性。没有训练、修改模型或运行新的动态控制实验。
所有qpos重建仅发生在诊断副本；不把重建过程记作电机驱动轨迹。

输入：`output/rl/target_load_ablation/2026-10-19_18-57-22-822502/report.json`。
正式结果：`output/rl/transition_geometry/2026-10-19_19-00-55-883261/report.json`。
此前19-00-18输出为加入最近内缩目标求解前的中间诊断，保留但不作为最终复现报告。

## 方法与边界

- 从实际完整初态恢复速度及电机目标；静态终点取成功3秒保持的最终帧。
- 三肢支撑区域采用左右手、右脚与地面的实际接触点凸包，不采用掌/脚site中心三角形。
- 计算质心垂直投影到凸包各边的最小有符号距离：正为内侧、负为外侧。
- 比较支撑site位置与两两距离，并做平面刚体配准以排除单纯全局平移/转向。
- 在当前三肢接触凸包内缩5mm的区域中求离当前质心投影最近的位置；仅2维凸几何问题，最多100迭代。
- 源报告、源代码、模型验证哈希；轨迹记录哈希，并检查重建载荷与原报告一致。

这只是准静态几何诊断，不包含摩擦锥、接触力矩、加速度或关节/力矩可达性。
质心在凸包外不等于动态运动不可能；进入凸包也不保证电机能够到达或保持。
支撑site变化不能区分接触滚动、滑动、重新落地；不能直接宣称旧终点发生违规滑移。

## 发现

| 状态 | 对该状态剩余三肢接触凸包的质心裕量 |
| --- | ---: |
| 当前真实起点 | -28.10mm |
| 原目标反馈3秒后 | -19.15mm |
| 三肢载荷目标反馈3秒后 | -24.00mm |
| 已验证静态三肢终点 | +59.79mm |

两种载荷反馈末端仍未把质心投影移入剩余三肢的接触区域，
这与未卸载结果一致，但不是完整因果证明。

静态终点相对当前初态：

- 质心水平位移约15.37cm，世界坐标分量为`[+4.52, -14.69] cm`。
- 左手、右手、右脚site水平位移分别约`1.90、3.11、2.20cm`。
- 左右手site间的水平距离增加约4.02cm；平面刚体配准后仍残留`1.86、2.91、2.14cm`。
- 左脚同时水平移动约18.05cm、site抬高13.39cm；最终几何净空约13.18cm。
- 最大关节姿态变化约0.439rad，涉及髋、腰及双臂，不是单纯小幅脚部动作。

因此旧静态终点不满足“支撑site固定，仅身体移重后低抬脚”的几何假设。
直接追踪它会同时改变支撑布局、全身姿态和摆脚高度，不适合作为最小过渡任务。

## 更小的几何目标

保持当前三肢接触区域不变，质心进入5mm内缩区域所需的最近水平偏移是：

`[+22.9235, -23.8764] mm`（世界坐标），长度`33.0994mm`。

目标世界位置：`[0.1070647, -0.0592318] m`。求解2次迭代，几何裕量5mm。
这不是身体底座必须平移3.31cm的指令；关节运动也会改变质心，且接触区域可能随运动改变。
它只提供比15cm远端姿态更局部、更可解释的规划目标。
