# 改装G1爬行：第一性原理路线重置

## 目标与停止旧主线

目标是可信模型中由合法电机驱动完成卸载—摆动—落脚—重新承重，并产生可重复前进。
静态保持、COM靠近某个点、IK节点可行、奖励提高，都不是该目标的替代品。
暂停COM纠偏/回退补丁链，不再围绕同一个5mm位置目标持续增加局部控制器。
历史代码、输入、模型和正负结果全部保留，不重写失败结论。

## 已有证据分层

| 证据 | 当前支持 | 尚未支持 |
| --- | --- | --- |
| 模型内四肢/部分三肢保持 | 存在局部承重构型 | 改装硬件参数真实、动态可达 |
| 几何路径节点可行 | 接触几何任务可满足 | 动力学、节点间连续性或力矩可行 |
| 实际电机移重安全运行 | 有局部承重运动能力 | 完整单步或周期爬行 |
| 多次原生重放一致 | 计算与记录可复现 | 模型已标定 |
| 固定PD偏置/短预测失败 | 有限方案不足 | 机器人无解、RL不可行 |

## 阶段A：模型与执行器可信度（本轮已实现首轮）

1. 对比工作区源XML与实际实验快照的编译参数，而不是仅比较渲染外观。
2. 导出质量、惯量、碰撞体、接触维数、摩擦、接触参数、排除碰撞对、关节/电机目标范围与限矩。
3. 在固定姿态计算ctrl范围实际可产生的静态关节力矩区间，区分关节角限位与电机目标范围。
4. 相同初态、相同控制，比较时间步、求解迭代与接触时间常数，禁止重新训练或针对各变体重新求平衡。
5. 标注哪些值只来自XML，哪些有用户改装资料/测量支持。没有资料时只能作模型内结论，不无限等待也不伪造标定。

## 阶段B：承重能力而非逐关节饱和比例（待执行）

首批已执行：`RL_COMPONENT_LOAD_CAPACITY.md`，新模型1个有效初始化平衡姿态、
1次基线与4种卸载LP；左手最低0N、右手7.780N、左脚2.986N、右脚70.775N。
这是实际4接触点上的保守静态近似，不是完整足底能力或动态卸载。
左手零载荷解有力矩边界，下一项先求内部裕量再做原生软接触一致性检查，不直接执行极值ctrl。

裕量检查已完成：`RL_COMPONENT_UNLOAD_MARGIN.md`。
左手零载荷存在正裕量解（最小电机余量3.613Nm），但同姿态合法ctrl的原生前向结果仍有左手17.89N，
基座线加速度0.233m/s²、角/关节加速度最大47.48rad/s²，未通过静态卸载。
力矩重建正确；下一项须联合调整姿态与接触，而非继续拟合固定姿态的理想接触力。

三支撑联合尝试：`RL_COMPONENT_TRIPOD.md`，单种子100迭代/60秒预算内41迭代失败，未运行保持。
末点左手离地2.412mm，但加速度与支撑位置/足底姿态不合格，不构成三支撑平衡。
下一项先在相同几何约束下构造几何初猜，再检查原生平衡，以区分几何冲突与动力学求解问题；
不沿着失败末点继续添加反馈或事后放宽约束。

分阶段检查已完成：`RL_COMPONENT_TRIPOD_STAGED.md`。
原几何约束3迭代可行；保持原参考/范围的原生平衡46迭代仍失败，未运行保持。
不再继续同一静态终点的初值搜索。下一项改为从已验证四支撑初态出发的短时动态卸载过渡，
执行前另行限定计算预算和安全门槛；几何解仅作软参考，不能当作成功数据。

短时动态减载已执行：`RL_COMPONENT_UNLOAD_RAMPS.md`。
固定0/0.10/0.25/0.50四组配对控制，0.25分支完成1秒且末段左手减载27.58%；
0.50在0.526秒因右手穿入5.0048mm停止。逐步重放通过，但左手未离地。
下一项冻结0.25做延长保持与平滑回撤，不追加局部幅度搜索，也不称完整卸载或稳定终点。

保持/回撤更新：`RL_COMPONENT_UNLOAD_RETURN.md`。
1秒减载后以1秒回撤、再保持2秒，通过相对基线的载荷/COM/速度/滑移恢复条件；
延长分支在3秒因右前臂地面载荷2.100N停止，尚未真正执行回撤。
保留可恢复短时减载为基线，停止继续扫描该方向的幅度/时长；后续须改变身体/支撑路径，
保留非支撑部件碰撞约束，不能把前臂接触屏蔽后宣称长期成功。

固定选择三个现有真实承重状态：历史两个loaded anchor，以及联合移重真实6秒末态。
不从大量候选中挑最容易成功的姿态。

上述三个状态仅对旧模型成立。新模型中将其作为固定初始化候选，先重新构造并验证承重；
未通过的候选单独报告失败，不进入静态受力筛选冒充有效初态。

目前新模型只有一个已验证保持状态，首批仅对应四种肢体卸载单元，
不能为凑齐旧协议的三个承重点而将未通过的历史初猜计入。

- 每状态分别考察四种目标肢体卸载，最多12个静态受力筛选单元，无重启。
- 求解接触合力/力矩平衡、摩擦限制及关节力矩约束，并纳入该姿态ctrl范围带来的力矩限制。
- 明确手部球形与脚部面接触能力；若采用离散点/摩擦棱锥近似，标记其保守性与遗漏的接触力矩。
- 输出最紧约束和目标肢体载荷下界/可行解，不用“最大力矩只有65%”代替整体受力判断。
- 固定姿态受力解仅是几何/受力筛选：原生软接触可能不实现该力分配；不可行也不否定其他姿态或动态步态。
- 零速度静态计算与真实运动状态明确分开；不得把重置速度后的状态当作真实过渡。

进入阶段C前给出可审计的肢体顺序选择依据，而不是默认沿用左脚优先。
阶段B求解器、每单元计算预算及近似模型须在执行前写入协议。

## 阶段C：完整单步，不以静态终点为中心（待执行）

根据阶段B只选择至多两种有依据的接触切换方案，联合处理身体运动、接触阶段与电机输入。
IK只作几何初猜；允许姿态与时序被修改，不要求固定支撑site或逐帧完全静止。

- 任务完整包含卸载、离地、摆动、落地和重新承重，末态还必须能继续下一步。
- 使用真实初态，实时只允许电机驱动；所有模型硬限位、非支撑接触和力矩约束明确。
- 保留原5mm工程筛选指标，同时单独报告接触参数敏感性，不能偷偷放宽阈值换成功。
- 完整接触事件、净前进、滑移、能量/功率及失败原因分别报告；不只展示最好一帧或单个载荷下降。
- 每方案只有预注册预算；两方案都失败就回到受力/模型假设诊断，不新增无止境局部补丁。

具体轨迹优化形式与计算预算在阶段B结束后决定；目前没有声称已实现完整轨迹优化器。
