实验日期：2026-10-30。

## 结果及范围

**已经得到并独立复验一条完整、连续的“真站立→双手落地→原冻结策略爬行”轨迹。** 总时长 4.16 秒，没有使用之前 175.82 秒的不对称扩步路径，也没有在落手后重置到低位姿态。

**这不是鲁棒控制器，也不是新训练出的 RL 过渡策略。** 它是两组协调关节关键点、接触触发的短过渡及现有冻结爬行策略组合而成的标称研究样例。八个预先固定的微小初始速度扰动全部失败，不能用于实机，也不能宣称一般初态下可用。

## 为什么这次路线不同

上一条路线逐步扩宽左脚，再保持双脚静态承重下降；各段成功并没有保证能连接到目标动作。本轮保留该路线作为旧承重基线，不再延伸。

本轮参考仓库已有的 Olson 视频观察记录：快速协调屈腿、展开与双臂落地。在线页面本轮未能通过浏览工具取回有效内容，未据此声称重新测量了作者视频，也没有作者的完整策略。

搜索从真站立直接进行，不固定脚、不强制 COM 始终位于支撑多边形，也不要求中途静态平衡。两类时序分别是展开领先和屈腿领先；每类 8 代×16 个候选，共 256 次搜索。双侧中间关键点共享 11 个坐标并按关节轴镜像，两组关键点加持续时间共 23 维；最终目标仍是现有爬行关节目标。它是结构化动态搜索，不是 3D 动捕，也不是 Olson 动作的精确复刻。

搜索排名使用有效物理前缀中的双手承重持续时间与较差一只手的间隙，不奖励单纯站着不倒或只降低骨盆。每步实际碰撞、力矩、关节限位、非支撑触地门槛均保留。失败步不计入进度，候选只有完成真正的爬行验收才算成功。

搜索报告：`output/rl/coordinated_contact_search/2026-10-30_15-51-20-975178/report.json`。屈腿领先候选曾双手承重约 216 ms，但继续原关节命令会非支撑触地；单凭它仍不算完整成功。

## 接管突变及处理

直接接管对照：`output/rl/coordinated_handoff/2026-10-30_15-54-27-102472/report.json`。双手接触后延迟 0/40/80/120/160/200 ms 切换，六次都在第一个爬行物理步触发力矩门槛；目标跳变约 0.95–1.29 rad。

新的独立过渡任务不修改冻结策略权重，也不修改原默认接管实现：

1. 接触事件到来时，按原规则一次性切到冻结爬行 PD 增益，不改状态。
2. 根据切换前实际关节力矩和新 PD 参数，计算保持瞬时力矩的控制目标起点。
3. 在 100 ms 内将该目标平滑过渡到不断更新的原策略目标；每 2 ms 使用 80% 力矩目标保护。实际力矩仍逐步检查 <95%，不是把超限值裁掉后再计分。
4. 过渡结束后，完全去掉保护/混合，保持策略历史连续，再执行原策略整整两秒。只在这两秒内验收前进距离和合格爬行周期。

9 组“接触延迟×过渡时间”对照：`output/rl/coordinated_blend/2026-10-30_15-57-58-235312/report.json`。只有立即接管、100 ms 过渡的组合通过。其他组合仍会触地或力矩超限，不能把更长混合时间视为天然更安全。

50 个过渡物理步中，30 步触发了控制目标保护；之后两秒没有继续偷偷限幅。独立审计在逐步重放原控制量的同时，重新运行冻结策略及其历史更新，确认后 1000 步控制量与原策略输出匹配。

## 独立验证与局限

`audit_coordinated_transition.py` 不调用搜索器或混合器执行动作；它重新从真站立逐步积分存档控制量，独立切换原增益、重算每步物理指标与爬行周期，并检查策略历史和纯策略控制量。qpos/qvel 与原轨迹在 1e-10 绝对误差内一致。另有关键点起终点、镜像关系、连续性、关节界限与非法过渡时间的回归测试。

固定参数后的扰动报告：`output/rl/coordinated_transition_v1/2026-10-30_16-03-06-020392/report.json`。初始 x/y 方向分别施加 -0.03/-0.01/+0.01/+0.03 m/s 速度，**0/8 通过**，失败为力矩或穿透。没有用这些结果继续调参数然后冒称留出集成功。

因此本版本完成的是**一个可复现的标称仿真转换样例**。对于“能否构造完整动态轨迹”的问题，它给出正例；对于“是否已有稳定的站立转爬行策略”，答案仍是否。下一阶段应将成功轨迹用作动态参考/课程种子，加入反馈及扰动训练，同时控制落手冲击，而不是继续以相同初态的成功替代鲁棒性。

## 使用

首次克隆后，在仓库根目录创建独立环境并安装已有校验固定的模型与策略资产：

```sh
uv venv --python 3.13 .venv-transition
uv pip install --python .venv-transition/bin/python -r rl/transition_v1_requirements.txt
.venv-transition/bin/python rl/install_crawl_assets.py
```

以下本机实验使用的 `/private/tmp/g1-transition-v1/bin/` 路径，在新机器上替换为
`.venv-transition/bin/`。成功轨迹、对应报告、搜索报告、过渡选择报告及八次扰动
评估报告及哈希固定的完整初态 bundle 随源码保存；其余历史实验产物不随本次提交上传。
资产安装器会校验并保留完整 bundle，不用旧发布包中的精简版覆盖它。

仓库根目录执行，无需重新搜索：

```sh
/private/tmp/g1-transition-v1/bin/python rl/run_coordinated_transition.py
```

可视化默认就是这条 4.16 秒成功轨迹，保留万圣节背景：

```sh
/private/tmp/g1-transition-v1/bin/mjpython rl/view_transition.py --loop --speed 0.5
```

空格暂停，R 重播，鼠标旋转/缩放。此命令回放存档，不是在窗口中运行新控制器。用 `--report <报告路径>` 查看指定版本；旧下降段仍可显式传其报告。

验证及固定扰动评估：

```sh

/private/tmp/g1-transition-v1/bin/python rl/run_coordinated_transition.py --evaluate-perturbations
```

模型与策略通过已有资产安装器获取。本次将该标称研究版本保存到 Git 分支，
