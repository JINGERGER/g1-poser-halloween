# 接触姿态约束对照

## 本轮改动

新增 `rl/contact_pose_path.py`，保留历史代码与报告哈希。
继承上一轮几何规划与原生回放，仅在IK残差中增加右脚碰撞几何体旋转矩阵相对初态的误差，
并解析计算旋转雅可比。执行前增加姿态误差≤0.001rad、地面间隙相对初态漂移≤0.1mm验收。
旋转是最小二乘目标，不声称优化器施加了严格等式约束；独立门槛负责拒绝超差结果。
间隙也是独立验收，不是本轮优化残差。

两条路径仍各最多10节点、每节点100次残差评估；三分支回放预算仍各6秒。
初态、移重目标、底座旋转固定、关节限位、相对姿态范围、控制器与物理阈值均不变。
没有通过几何检查的候选不执行；不延长时长、不提高预算、不放宽阈值。

总耗时约0.73秒；这不是6秒仿真的实时耗时承诺，而是本次离线运行的墙钟时间。

右脚原先的离地问题得到抑制：先移重路径前3节点、联合路径前6节点的右脚间隙
保持约-1.354mm。但这不是整体路径成功；左脚仍可因姿态变化而穿地/重新接触。
末失败节点优化器均报告收敛，证明不能把优化器success当物理/几何通过。

两条失败候选都触及底座高度相对上界+2cm、左右踝roll上界，以及多个髋/肩/腕范围边界。
这些边界混合了模型实际限位和本实验±0.5rad信赖范围，不能统称电机真实能力极限。
底座旋转固定也是人为搜索限制，本轮失败不证明完整构型空间不可达。

## 整体判断：停止逐点补丁式IK

后续统一接触模式与控制范围实验已完成，见 `RL_CONTACT_MODE_PATH.md`。
四候选几何均通过；纳入含偏置的电机目标范围后完成真实回放，但尚无实际卸载/抬脚。

本轮支持“点坐标约束不能替代接触姿态”的判断，但只锁右脚仍不是完整接触模式。
继续逐个锁关节、调姿态正则或放松阈值，会退回局部补丁路线。
下一版必须统一定义接触阶段和几何约束，再讨论动力学：

1. **四肢移重阶段**：四个实际碰撞几何体保持接地，不能仅检查剩余三肢。
   当前继承的检查允许左脚提前离地，例如先移重路径1秒节点左脚间隙+2.224mm；
   该节点虽通过旧几何门槛，也不构成符合“四肢移重”语义的路径。本轮没有执行它。
2. **左脚离地阶段**：其余三肢接触保持，左脚实际碰撞几何体非穿透、净空受控，
   不能只让脚site向上移动。姿态变化导致的离地与穿地都应进入规划约束，而非事后偶然发现。
3. **接触几何适配**：球形手部接触约束球心/间隙，脚部约束接触面位置和法向；
   是否允许绕法向旋转需要明确，避免无必要锁死完整3轴旋转。
4. **可达性对照**：在完整接触表示下，先比较底座旋转固定与允许小幅旋转，
   使用相同预算与模型硬限位；不要用扩大所有关节范围替代诊断。
5. **动力学阶段**：几何合格才检验原生接触承重、PD偏置/力矩分配与动态跟踪。
   几何成功仍不算物理成功，失败也不能先归咎电机。

此统一接触模式规划尚未实现；不把当前结果计作成功卸载、抬脚或爬行示范，零RL更新。
