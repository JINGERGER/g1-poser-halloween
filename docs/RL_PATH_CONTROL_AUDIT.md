# 固定安全路径的承重控制审计

## 本轮范围

固定 `control_feasible_path/2026-10-19_19-29-30-266151/report.json` 中
`shift_then_lift_rotation0` 路径，不修改姿态节点、时长、模型、控制增益或安全门槛。
新增 `rl/path_control_audit.py`，重建10个节点的参考姿态与原生执行状态，比较
质心、关节误差、PD力矩、实际接触载荷和参考静态加速度。

另在路径0、3、5秒三个固定姿态上，各做一次仅23电机目标可变的原生接触拟合：
每次最多100次最小二乘主残差评估、无重启、ctrl范围不放宽，姿态不变、诊断副本速度为零。
优化目标为归一化qacc及微弱ctrl变化正则；有限差分调用单独记录，不能把100当总调用次数。
独立静态验收要求基座线加速度范数≤0.01m/s²、角/关节最大加速度≤0.1rad/s²，
以及穿透、非支撑载荷、力矩比例门槛。优化器收敛不代表验收通过。

报告：`output/rl/path_control_audit/2026-10-19_19-32-33-607976/report.json`。
本轮没有新增动态回放或RL训练，不把诊断副本置零速度算作真实轨迹的一部分。

## 更基础的负载一致性问题

机器人重力约312.14N。5秒参考姿态使用原偏置时，支撑载荷约
`[86.81,42.16,0,136.53] N`，合计约265.50N，少了约46.64N。
该姿态的其余支撑碰撞间隙沿用了初始值，而左脚原先承担的约46.8N被直接移除，
并没有保证其余三肢获得相应增载。**几何上抬脚，并不自动满足承重平衡。**

仅调ctrl后末端支撑合计约259.80N，仍未平衡。接触力会随姿态、速度和控制共同变化，
不能把这些数值解释为固定间隙唯一决定载荷；但当前试验已否定“这几个固定姿态加原PD偏置就是平衡路径”。
局部拟合失败也不能证明所有ctrl或所有附近姿态都不可能平衡。

## 决策与下一步

后续联合姿态/ctrl实验已完成，见 `RL_JOINT_SHIFT_EQUILIBRIUM.md`：
移重平衡点通过3秒原生保持；真实6秒过渡安全，但COM偏差7.64mm超过5mm到达门槛，尚未通过真实到达。

不再单纯增加PD增益或继续追踪这条几何路径。下一步把它作为几何先验，而非固定的动力学参考：

1. 先取3秒移重节点，允许小幅全身姿态/支撑间隙调整，同时求合法电机目标；
   让原生接触承重和qacc进入约束，保持支撑位置、碰撞、ctrl/限矩门槛。
2. 与本轮“姿态固定、仅调ctrl”作为对照，用明确的单次求解预算；不复用理想接触力解冒充原生结果。
3. 独立静态验收通过后，先做假设初态短保持，再从真实初态电机驱动过渡；两者分开报告。
4. 移重阶段真实可达后，才能求卸载/2cm抬脚阶段，随后落脚、前移、重复周期。

这是必要的几何与承重联合验证，不是已经实现全身动力学优化。
之前的接触几何工作保留为约束与初始化，但不继续扩大IK搜索或用RL步数掩盖不平衡参考。
