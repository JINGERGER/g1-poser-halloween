# 接触力约束的三肢支撑候选

## 固定问题（2026-10-19）

上一轮随机节点搜索没有卸载。本轮改为明确求解约束，不继续扩大随机搜索。
两个真实带载初态，各做四肢支撑对照与右脚离地2cm三肢支撑候选。
每个局部 SLSQP 求解最多150迭代/90秒，不重启、不自动追加预算。

- 变量：浮动基座位置/朝向、23关节、保留支撑点的三维接触力。
- 基座搜索范围：水平±15cm、高度±8cm、旋转增量各±0.4rad；关节增量各±0.5rad，另受原关节范围约束。
- 约束：浮动基座力/力矩平衡，单向法向力，保守菱形摩擦锥，支撑肢总载荷>5N，
  原电机限矩95%及原目标角限幅，非支撑部位不接地，右脚碰撞几何净空≥2cm。
- 支撑点使用原带载状态的实际接触点，允许水平5mm/竖直2mm变化；支撑几何间隙限制为[-5,2]mm。
  没有增加接触点、改变摩擦或移除自碰撞；接触点本身不提供扭转/滚动接触力矩。
- 目标仅为小姿态变化与小接触力范数。验收按独立约束容差，不按目标函数大小。
- 静力所需关节力矩反解为原位置伺服目标角，检查其重构误差。

**这是刚性接触力松弛问题，不等同于 MuJoCo 软接触平衡。** 数学约束通过后必须分别验证：

1. 假设初始化到候选姿态、零速度，原生物理保持3秒：只验证候选，不证明可达。
2. 从原始真实带载状态和原速度出发，0.5秒后用3秒平滑过渡目标角，仿真至6秒：
   仅发送限幅/限速电机目标，不强写位姿、不施加外力。时间参数本轮固定，不声称已优化时序。

全段穿透>5mm、非支撑载荷>1N或机身高度越界即停止。
安全验收另要求平均承重滑移≤2cm/s、接近力矩上限的端点比例≤10%。
保持实验1秒后/过渡实验4秒后的每个端点，右脚无接触、载荷≤1N、净空≥15mm，且其他三肢各承重>5N，才算持续三肢支撑。
四肢对照不要求右脚离地；只验承重安全，不能计作运动成功。
即使过渡通过，也尚未包含落地、完整循环或前进，不能称为已实现爬行。

## 实测与核验

最终报告：`output/rl/contact_seed/2026-10-19_11-15-38-384833/report.json`。
四个数学问题均在既定约束容差内。三肢候选1优化器正常收敛；候选2达到150迭代上限，
但等式最大归一化残差约1.00e-13、不等式最小余量约-1.29e-8，仍满足独立的1e-5约束容差。
**约束可行不等于优化目标收敛，也不等于原生物理可行。** 静力支撑下限实际为≥5N。

| 2 / 四肢 | 通过 | 3s通过 | 6s通过 |

三肢四次重放的超限部位均为右手掌与地面；没有观察到禁止部位承重或接近电机限矩端点。
这些短回放因既定工程门槛提前停止，不能声称已经倒地，更不能根据它们证明电机无法承重。
5mm是当前验收标准，不是已经标定的改装接触垫物理极限；本轮没有为了通过而修改它。

### 为什么数学约束不够

候选静力分配与原生零速初态的实际接触载荷不同，顺序为左手、右手、左脚、右脚：

- 初态1计划约 `[5.00, 174.05, 133.10, 0] N`，原生约 `[20.68, 157.74, 137.90, 0] N`。
- 初态2计划约 `[5.00, 148.62, 158.53, 0] N`，原生约 `[24.33, 129.23, 12.81, 0] N`。

关节目标反算的伺服力矩误差≤1.3e-12Nm，但原生初态仍有非零基座加速度。
因此接触力不能作为独立、任意可实现的变量：本轮松弛未约束其与软接触几何/速度的对应关系。
同时两个三肢解都把左手载荷推到5N下限，支撑余量不足也是后续必须考察的问题。
这不是对所有三肢姿态的否定，只说明这两份松弛解不能直接成为可用物理示范。
