# 从实际承重状态接续运动（2026-10-16）

## 本轮回答的问题

不是继续找静态三肢姿态，也不是再训练。先检查能否获得可接续的实际承重状态，
再用一个固定幅度的右后脚探针观察卸载反应。结果：**承重起点可用，单独的局部抬脚残差未完成卸载**。
不能称为已实现抬落或爬行，也没有证明全身控制不可行。

输出：`output/rl/support_handoff/2026-10-16_14-30-00-993045/report.json`。
脚本：`rl/support_handoff.py`；检查：`rl/check_support_handoff.py`。
本轮共两个已有训练种子 × 三个分支，各运行 13 秒仿真；新增训练更新为零。

## 固定设计

- 已有 force-corrected、零速支撑策略：`2026-10-15_11-42-03_mujoco` 和
  `2026-10-15_11-48-28_mujoco` 下的 `model_299.safetensors`。
- 固定评估 seed=2001，每个策略只用单环境第一个回合，不筛选最好初态。
- 先运行真实闭环支撑 10 秒。要求最近 1 秒每个采样都四肢承重 >1 N、非末端负载 ≤1 N、
  穿透 ≤5 mm、力矩利用率 <95%，否则不进入后续分支。两种子均满足。
- 保存完整物理状态、qpos/qvel、上一 ctrl/action、观测和状态哈希。三个分支分别从同种子重跑，
  10 秒处物理状态和观测哈希完全相同，而不是把动画帧重置成零速度。
- 分支 A：继续原支撑策略 3 秒；分支 B：保持最后一个 action/ctrl 不变 3 秒。
  冻结的是目标角，不是固定关节、基座或模拟状态；原生 PD 和接触仍在运行。
- 分支 C：原支撑反馈上叠加右腿关节残差。只用 6 个右腿关节作离线 IK，
  在独立几何副本上构造右脚 site +2 cm 的目标，单关节残差不超过 0.15 rad。
  0–0.5 秒零残差；0.5–1.25 秒平滑抬升；1.25–1.75 秒保持；1.75–2.5 秒回落；最后 0.5 秒零残差。
  本次最大关节偏移约 0.0731/0.0740 rad，几何 IK 残差 <1e-15 m。
  这是几何可达性，不是动力学可达性；2 cm site 目标不能当作碰撞几何净空。
- 实际批量物理过程不强写 qpos、不施加外力、不变更模型参数。每步用真实 ctrl 原生重放诊断，
  包含终止前状态。最大状态误差 4.58e-7；所有分支都存活到 13 秒。
- 核对本轮模型与短程实验的当前 PD 模型：质量/惯量、关节位置/范围、阻尼/armature、
  碰撞几何/摩擦/接触参数、执行器增益/限矩、自碰撞排除等已检查的 28 个数组均相同，
  timestep=0.002、重力相同。并非换了轻量机器人；任务传感器配置不同，不宣称 XML 完全相同。

## 能排除什么，尚未回答什么

1. 本次起点不是前轮“右脚离地 26 cm、零速度落下”的状态；继续支撑对照能持续承重。
2. 冻结已有带载目标也能接续至少 3 秒，说明下一阶段可以使用这个局部基准，
   不必先将支撑策略训练到完美。冻结分支滑移较小只适用于这两个短窗口，不作普遍优劣结论。
3. 仅有局部腿部几何 IK 和小幅残差不足以让这两个起点卸载；不能把 IK 精度误认为物理动作成功。
4. 不能据此区分支撑策略的反馈抵消、基座补偿、接触受力分配各自的贡献；
   没有测过“冻结目标 + 同残差”分支，因此不能声称一定是策略在抵消。
5. 单回合、3 秒接续不等于稳定控制器；20 ms 端点指标不是子步峰值，更不是实机验收。

## 下一步的明确边界

保留这两个带载起点及其继续支撑对照。下一段构造要联合控制基座/支撑载荷转移与右脚动作，
以右脚负载接近零、其余三肢继续承重、无躯干承重为前置反馈，再执行抬落。
不得通过增加腿部偏移幅度、延长播放时间或放宽碰撞阈值来宣称成功。
本次尚未实现该全身转移控制器，不把局部 IK 探针包装成完整方案。

## 实际负载门控的重心转移（2026-10-16）

新增 `rl/load_transfer.py`，不加载策略、不训练，直接恢复上述两个已保存的 10 秒带载物理状态。
保留末次带载 ctrl（而不是令 ctrl=qpos），以连续原生 MuJoCo 积分推进。
每个起点只做冻结目标和一个转移方向，最多 7.5 秒；无参数扫描。
最终报告：`output/rl/load_transfer/2026-10-16_15-37-12-780171/report.json`，含完整状态/控制轨迹。

### 方法与门槛

- 以其余三肢 site 的水平中心为几何方向，目标水平转移范数限制为 8 cm，0.5 秒后用 3 秒平滑增加。
  原始中心位移约为 20.8 / 19.3 cm，实际使用的是裁剪后的有界尝试；中心点不是必要目标，
  更不是摩擦锥/动态可行性证明。不能因走不到这个中心就认为模型不可行。
- 保持末端世界位置，在独立 IK 数据副本上移动虚拟根位置，求取全身关节偏移。
  实际机器人根部没有被写入或固定；仅通过原 PD 的目标角产生运动。
- 使用测得的全身 COM 位置作有界反馈修正；单关节偏移 ≤0.25 rad、ctrl 每控制步变化 ≤0.01 rad，
  并保留原模型 ctrl/力矩限值。没有外力、没有改变质量/接触/增益。
- 右后脚负载 ≤5 N 且其余三肢均 >5 N，持续至少 0.1 秒才允许进入抬落序列；
  等待及抬升时若重新承重或丢失其余支撑则停止，不沿用过期的卸载判定强行抬脚。
  抬脚仍只请求 2 cm site 高度，真实离地必须另由几何间隙和接触确认。
- 子步穿透超过 5 mm、端点非末端负载 >1 N、根高度 <16 cm 或 IK 残差 >5 mm 即停止。
  5 mm 是既有工程筛查门槛，不是判定整个系统动力学不可行的物理定律。

### 结果

| 起点 / 分支 | 时长 | 右后脚初始负载 | 最低负载 | 结果 |
| --- | ---: | ---: | ---: | --- |
| seed1 / 冻结 | 7.50 s | 112.08 N | 112.03 N | 完成，无非末端承重 |
| seed1 / 转移 | 2.96 s | 112.08 N | 57.11 N | 左手与地面穿透达 5.031 mm，停止 |
| seed2 / 冻结 | 7.50 s | 87.06 N | 87.33 N | 完成，无非末端承重 |

最低负载统计从第一个 20 ms 端点开始，不包含初态，因此 seed2 冻结分支的最低值略高于初始值。
两次转移均没有触发卸载，**没有执行抬脚请求，四肢完整抬落事件均为零**。
全部分支观测到的非末端负载为零；这次停止不是躯干塌落。
两个转移的子步峰值力矩利用率为 40.69% / 44.28%，也不是已经达到模型限矩。
两次 IK 几何残差 <1e-15 m、ctrl 无裁剪，说明几何跟踪目标可构造，但并不说明接触受力可按目标分配。

seed1 结束时四肢负载约 94.64、89.01、70.09、57.11 N；相比起点，主要增加的是两手承重。
seed2 对应 94.88、67.76、68.01、80.99 N，右后脚卸载很少。
这是“朝三点中心移动”启发式的局限，不能将 COM 位移直接等同于右脚卸载。
实际 COM 末位移约为 (9.26, 6.83) / (7.04, 3.99) cm；8 cm 是命令约束，不是实际物理位移上限。

### 解释与后续边界

本轮确实改变了支撑负载，但还未获得三肢接替负载的可执行片段。
冻结对照再次表明起点可维持；转移先触及左手接触压入门槛。
这既不能当成“机器人必然爬不动”，也不能仅因为超过门槛很少就自动放宽或改硬接触。
后续应明确三肢接触力分配及其接触压入约束，避免把卸载主要转成前手承重，
而不是继续增加一个重心位移数字或抬脚幅度。
模型中的接触参数是否与实体手部材料相符仍未校准，不做实机可行性声明。
