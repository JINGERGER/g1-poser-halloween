# IK 参考的短程物理可行化

## 问题与边界（2026-10-19）

本轮不调 PPO、不延长旧训练、不精修动画。验证：在相同物理模型、带载初态、控制空间和预算下，
几何 IK 初始猜测是否帮助找到真实的卸载—抬起—落地和少量推进。
这是一轮有限直接射击轨迹搜索，不是全局可行性证明，也不是完整爬行控制器。

## 冻结实验

- 两个已有 10s 带载状态，各比较无 IK 与右脚 2cm 几何 IK 初始猜测；保留初始速度和预载目标。
- 每段 4s；23 个关节各有 3 个自由控制节点，共 69 个变量。
  优化全身电机目标，允许参考被改变；本轮固定时间节点，不声称已做时序或接触序列优化。
- 自由节点范围 ±0.2rad；相邻控制目标变化 ≤0.01rad/20ms，并使用原控制限幅。
  起末节点回到预载目标；实时仿真仅写 ctrl，不写 qpos、不施加外力、不修改摩擦/电机能力。
- 两分支使用相同优化随机种子 20261019；每分支 6 代×16 候选，加一次初始轨迹评估，最多 97 条轨迹。
  每分支搜索上限 120s，超时保留当前结果，报告 budget_limited，不自动加时。
- 搜索使用交叉熵式精英更新；先按安全约束排序，再按卸载、离地和推进误差排序。
  所有候选的指标保留，不能只汇报最优奖励。
- 比较两种初始化是消融，不是宣称比较了所有 RL/轨迹优化路线；两个锚点也不等于泛化验证。

## 通过标准

右脚完成至少一次连续卸载抬起和落地：原有判据保持为离地 ≥15mm、无接触、载荷 ≤1N 持续 ≥60ms，
随后载荷 >1N、间隙 ≤3mm 持续 ≥60ms；起飞前必须先确认承重。
最终沿初始身体方向推进 ≥1cm，侧偏 ≤3cm，末态广义速度 RMS <0.2（混合单位的数值停稳筛选，不是硬件标准）。
另要求全段穿透 ≤5mm、非支撑接触载荷 ≤1N、平均承重接触滑移 ≤0.02m/s、
接近力矩上限的端点比例 ≤10%、机身高度 0.16–0.65m。
穿透逐物理子步记录；载荷/滑移/力矩每20ms采样，不能宣称无子步尖峰。

一次右脚片段即使通过，也只证明该初态下的局部运动，不证明四肢连续爬行、鲁棒控制或真实电机能力。
失败则只否定本轮参数化和预算，不否定机器人物理可行性。

## 停止与分流

- 有通过片段：先独立重放，再扩展其他肢体/完整循环，最后作为 RL 软参考；不立即训练楼梯。
- 安全候选只有站立：将瓶颈明确为接触切换未找到，不继续单纯调 PPO 探索噪声。
  下一设计应比较更适合接触切换的任务空间/接触时序参数化，而非机械延长同一高维随机搜索。
- 放松穿透、允许膝盖承重等属于任务/模型变更，不能为了通过而偷偷修改。

### 决策

本轮未找到可作为物理示范的片段；不把1cm机身位移包装成爬行，不把安全静止当成功。
两种初始化均无真实接触切换，**没有证据显示这份纯几何 IK 在本轮搜索中带来决定性帮助**。
结论范围仅限固定时序、69维关节节点、当前幅度/预算；不能由此否定 IK 或机器人物理可行性。

停止追加同一随机搜索，不回退到无限 PPO 噪声微调。
下一路线应把接触切换显式纳入问题：三肢承重/目标肢卸载约束、可变身体姿态和阶段时长，
再进行动力学重放验收，而不是只增大抬脚参考或提高离地奖励。
这需要另一个明确设计的求解方案；本轮没有实现接触约束求解器，也没有产出可训练的成功示范。

后续已实现独立接触力约束求解与原生验收，见 `docs/RL_CONTACT_SEED.md`。
两份三肢候选满足静力松弛约束，但未通过原生保持；四肢对照通过。
因此尚未产出可用于训练的成功三肢片段，不能把静力解误记为物理运动成功。
