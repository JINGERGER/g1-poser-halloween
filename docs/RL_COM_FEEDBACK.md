# 真实移重末态的配对COM反馈

## 固定协议

输入：`output/rl/joint_shift_equilibrium/2026-10-19_19-36-02-747597/report.json`。
完整重放真实6秒电机过渡，逐帧验证qpos/qvel，然后获取完整物理状态与当前ctrl；
两分支从完全相同的状态开始，保留时间、速度，不以静态姿态重新初始化。
目标仍为上一轮联合求解的四肢移重平衡点COM，5mm到达门槛不变。

实现 `rl/com_feedback.py`，复用冻结的局部有限差分控制拟合器，但使用明确的COM反馈特征：

- COM xy误差/1cm、基座线速度/0.2、基座角速度；不优化任意肢体载荷目标。
- 保持原ctrl与新反馈两组各最多3秒；预测0.2秒、每0.1秒重规划，最多30次/1530次预测。
- 每关节中央差分±0.003rad、目标信赖范围±0.015rad；回查比例1、0.5、0.25、0.125。
- 每20ms电机目标最大变化0.01rad；ctrl范围、PD增益、模型与力矩限位不变。
- 预测检查穿透≤4.95mm、力矩比例<0.95、非支撑载荷≤1N、四肢接地且各>5N。
  实际穿透门槛仍5mm，滑移与近限矩比例验收保持原标准。
- 到达要求完整3秒，末1秒COM误差≤5mm、每个广义速度分量绝对值≤0.05，且安全检查通过。
- 无合格预测候选立即终止本次仿真；不增加时长、放宽阈值或改变目标。
  该停止行为不是经过验证的硬件制动/恢复控制器，也不证明停止后的状态能够无限保持。

## 判断与停止条件

恢复审计已完成，见 `RL_RECOVERY_AUDIT.md`：保持、回退及4个原纠偏候选均未通过预测穿透门槛，
没有执行恢复动作。下一步应在第一步接受前检查后继安全路径，不能默认停止后仍可安全回退。

当前平衡点附近的安全余量很小：前轮真实过渡峰值已约4.908mm。
这次局部反馈能够产生纠偏方向，但有限差分+有限候选回查没有保证后续规划继续有解。
一次0.2秒预测通过也不构成递归可行性或长期安全证明。

不放宽4.95/5mm门槛、不继续重复微调COM权重、不用延长时间掩盖候选耗尽。
下一步应先审计失败状态的可恢复性与接触余量，而不是继续逼近原COM目标：

1. 保留这个真实停止状态，记录所有候选的具体约束裕量与终端速度，补足拒绝原因可观测性。
2. 对比保持/回退目标的原生预测，确认有没有可执行的安全恢复动作；“回退旧ctrl”本身也必须验证。
3. 若存在恢复动作，再将安全恢复候选与终端约束纳入反馈；若不存在，回到上游过渡末态设计，
   不把静态平衡点可保持误当成任何邻近状态都可恢复。

本轮不进行额外参数搜索或新平衡点优化，零RL更新。
