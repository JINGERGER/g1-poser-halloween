# v0.1.0-halloween — 仿真预发布版

## 内容

- 改装23执行器G1的原生MuJoCo平地闭环爬行。
- 草坪墓地、南瓜灯、幽灵和三位骑扫把飞行的巫婆；装饰不参与碰撞。
- macOS独立爬行viewer入口，以及原IK编辑器的macOS启动适配与`--physics`参数。
- 带SHA256的独立运行资产包，干净克隆不依赖UniLab、邻接参考仓库或本机绝对路径。
- 三次名义重复、步长/朝向检查、逐子步物理重放和独立步态验证工具。

## 验证与限制

冻结配置在本机Apple Silicon CPU上三次名义10秒运行各前移约4.81m，
各通过22个完整对角步态周期；1ms步长及±0.03rad初始偏航另列检查通过。
这些不是随机环境泛化成功率。发布前另在不带UniLab或邻接参考仓库的干净目录验证安装和运行。

该控制器使用上游RL策略及确定性控制修正，不是新训练的PPO权重。
PD采用参考配置；接触solref时间常数0.005。机器人质量、几何碰撞、摩擦、
关节限位和电机限力不因背景装饰改变。原未修正配置的失败不追认为成功。
`0.08m`为受限抬升修正请求，实际脚部峰值约3cm、手约4cm。

**不保证**爬坡、上下楼梯、任意速度/转向、长期运行、真实草地或真机安全。
原编辑器场景中的斜坡不是爬行能力演示；爬行运行入口明确不导入斜坡。
GUI绘制窗口未在发布打包阶段人工验看；无窗口闭环和场景动画物理隔离已测试。
