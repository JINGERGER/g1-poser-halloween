# 手臂碰撞体组合覆盖核对

## 固定问题

上一轮发现前臂胶囊在打印件后方延伸；本轮检查该胶囊是否同时代替肘部硬件，
以及上臂胶囊、前臂胶囊、20mm手球的**组合**是否覆盖已知外形。
不把单胶囊未覆盖的点直接计为整个手臂漏碰撞。

实现：`rl/arm_collision_coverage.py`；检查：`rl/check_arm_collision_coverage.py`。
报告：`output/rl/arm_collision_coverage/2026-10-19_20-16-46-007497/report.json`。
模型与上一轮相同，使用原定42个局部姿态，不重新搜索姿态或调控制器。

## 坐标与来源

- 打印壳体采用已经配准的3MF顶点与三角形重心。
- 上臂、肘部采用模型中对应可视mesh的顶点与三角形重心，不把可视mesh直接启用为碰撞体。
- 编译后的mesh顶点通过geom世界变换转换，处理MuJoCo编译mesh时的重定位；不能只套body变换。
- 独立检查将编译mesh还原到body坐标，其包围盒与原始二进制STL比较，误差容限0.1微米，检查通过。
- 检查模型、manifest、mesh、CAD及上游报告哈希；旧模型文件不改动。

## 结果

每个样本取到同侧上臂胶囊、前臂胶囊、手球的三个有符号距离的最小值。
正值表示点在三个体外；对组合外部的点，这给出到该组合的距离。

| 外形 | 每侧样本数（左/右） | 组合外超过1mm的样本数（42姿态范围） | 最大外距 |
| --- | ---: | --- | ---: |
| 上臂可视mesh | 7475 / 7499 | 左4904–4923；右4942–4994 | 22.27mm |
| 肘部可视mesh | 2679 / 2663 | 左2125–2154；右1983–2142 | 17.14mm |
| 打印壳体CAD | 9658 / 9658 | 两侧均5151 | 7.13mm |

两侧肘部body都只有可视geom，**没有独立的启用碰撞geom**。
前臂胶囊向安装端后方延伸，确实可能承担部分肘部覆盖，但组合并未覆盖所有肘部外形样本。
它挂在腕滚转body上，不能未经核对就把这种覆盖视为肘部刚体的可靠碰撞表示。

壳体的组合最大外距为7.13mm，而上一轮对单胶囊的结果为20.98mm；
手球确实补足了一部分末端覆盖，但仍不能把这个组合当成完整壳体近似。

以上是**同侧三个碰撞体组合**，不是机器人所有碰撞体的并集；肩部等其他几何可能覆盖部分点。
样本数不是表面积比例，外距不是实际发生的穿透深度。
这些外形有文件来源，但仍不是硬件实测；结果不证明机械干涉或爬行不可行。

## 决策：结束这一轮覆盖清单，进入单一模型候选

现有胶囊既混用部件又漏掉外形，不再追加控制器补丁，也不继续无限扩大几何扫描。
下一版采用独立、明确标注保守性的部件碰撞候选：

1. 上臂和肘部各自使用其body坐标下的外形近似；肘部碰撞跟随肘部body。
2. 打印壳体使用分离的CAD壳体，手球保持20mm，不使用包含球体的完整forearm STL凸包冒充壳体。
3. 单凸包可作为保守外包候选，但可能填实孔洞或装配凹槽，不能冒充真实实体；若导致安装区域假碰撞，定位后处理，而不是盲目关闭全部自碰撞。
4. 保留显式质量/惯量、执行器和接触参数；新geom不自动改变质量。
5. 先复查固定42个局部姿态和115个全限位样本，区分安装邻接重叠与非邻接碰撞；通过不代表全关节空间安全。
6. 在有记录的工作区接受条件下，立即转入重新构造20mm球的初始接触与带载保持，不再把几何审计当作动态进展。

候选若不能合理描述装配，记录阻塞几何对；不通过恢复35mm球或扩大排除范围制造成功。
本轮尚未实现上述新碰撞候选，没有动态rollout，没有新增承重结论。
