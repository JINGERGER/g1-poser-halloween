# 爬行工作区手臂碰撞定位

## 问题与固定检查范围

不再把全限位扫描中的大穿透直接解释成爬行不可行，也不先取消碰撞排除。
使用20mm参考球心模型，对旧名义姿态、旧平衡姿态各检查一次基准，以及10个手臂关节
分别±0.1rad的单关节扰动（按限位截断），共42个几何姿态。基座抬高1m隔离地面。
这些不是新模型带载初态，不运行控制器、不训练、不改变模型。

报告：`output/rl/local_arm_geometry/2026-10-19_20-13-54-459839/report.json`。
实现：`rl/local_arm_geometry.py`；复查：`rl/check_local_arm_geometry.py`。

使用已配准3MF的3206个顶点及6452个三角形重心，共9658个壳体表面样本。
分别检查：上臂/前臂胶囊的直接距离、壳体样本到上臂胶囊的有符号距离、实际启用的自碰撞。

## 结果

- 42个姿态均无超过1mm的启用自碰撞。
- 被排除的上臂/前臂胶囊仍重叠29.30–35.78mm。
- 所有姿态中，壳体样本到上臂胶囊的最小距离为正，范围44.06–64.56mm；没有样本进入上臂胶囊。
- 旧名义姿态的胶囊距离见证点在前臂局部x约-77mm与-93mm；实际打印壳体从x约+2.2mm开始。

所以当前证据把该重叠定位在**打印件后方的碰撞近似延伸部分**，不支持“打印壳体正在撞上上臂”的解释。
但是这里可能还包含肘部电机/连杆硬件，不能直接裁掉该部分或认定碰撞排除完全合理。
正的采样距离也不是完整实体之间无干涉的证明，尚未核对真实上臂及肘部外形。

## 近似不能代表打印壳体

现有前臂胶囊轴向从-80mm到145mm、半径25mm；其整体轴向范围约-105mm到170mm。
打印壳体轴向范围为2.2mm到185.673mm，横向最宽约62mm。
9658个样本中6949个在该胶囊外超过1mm，最大外距约20.98mm。
这仅比较**前臂胶囊单体**，不等于这些点都在整个机器人碰撞体并集之外；末端还有手部球体。
样本比例不是表面积比例，也不是实体体积覆盖比例。

因此不能仅把原胶囊缩短便宣称恢复实物碰撞：它既向安装端后方延伸，也没有单独覆盖壳体外形。

## 下一步决策

1. 区分打印壳体、肘部硬件和上臂三个部件；单独定义壳体碰撞近似，不让一个胶囊隐式承担三者。
2. 先对已有肘部/上臂可视网格核对装配与局部近似覆盖；这些网格有来源但不是实物测量。
3. 若构造新近似，建立独立版本并复查这42个固定姿态及原全限位扫描，不以减少碰撞数作为唯一成功条件。
4. 完成工作区核对后再重建20mm接触球的四肢带载初态；不将纯几何无碰撞解释成承重或电机移动能力。

这一轮只定位一个模型问题，不据此再添加反馈控制补丁。质量/惯量与接触柔度的不确定性仍保留。
