# 接触模式与可执行控制范围：两轮有界对照

## 目的与设计

从“逐个脚锁姿态”转为完整接触模式，并区分几何规划、控制范围和真实动力学三个层次。
不改变物理模型、摩擦、增益、限矩或5mm穿透门槛。保留同一真实初态与速度。

第一轮 `rl/contact_mode_path.py`：

- 两种时间调度（先移重后抬脚、联合移重抬脚）×底座旋转固定/小幅可变，共4候选。
- 球形手部约束实际碰撞球心xy与地面间隙；盒形脚部约束碰撞几何中心xy、
  地面间隙及局部z轴方向。不固定完整脚部旋转，允许法向周围旋转。
- 双脚均纳入上述表示，包括摆动左脚；净空目标来自实际碰撞几何而非site高度。
- 移重阶段四肢接地；开始抬脚后剩余三肢接地。左脚目标间隙从初值平滑变化至20mm。
  软接触初始穿透保留，不假装初态是硬接触零间隙；开始抬脚不等于已完成动力学卸载。
- 底座旋转可变组使用初态局部旋转向量，每分量±0.15/√3rad，总角度≤0.15rad。
- 每候选10节点、每节点最多100次残差评估；每分支最多6秒原生回放，零重启。
- 几何验收：xy/COM误差≤1mm、间隙误差≤0.1mm、法向向量误差≤0.001，
  原穿透与非支撑几何检查保留。最小二乘目标不等于严格约束，通过独立门槛才执行。
- 解析球/盒间隙与解析任务雅可比；旋转参数到MuJoCo切空间的转换用小扰动求导。
  100次指残差评估预算；雅可比运算和最终验收另计，不冒称总计算量与旧模型完全相同。

## 第一轮：几何全部通过，电机目标被拦截

报告：`output/rl/contact_mode_path/2026-10-19_19-28-09-494908/report.json`。
4候选的全部节点通过，末左脚几何净空约20mm，固定底座也可以找到节点路径。
因此先前失败不能简单归咎于固定底座旋转；接触几何表示影响更直接。
这是离散几何结果，尚不保证节点间连续可行或动力学可达。

全部候选在原生回放前因`biased_targets_exceed_ctrlrange`被拦截。
定位均为右踝roll：沿路径叠加初始承重偏置后，电机目标最多超限约0.02545rad。
关节角在限位内不代表含PD偏置的电机目标也合法。
没有裁剪目标后偷偷执行，也没有放宽模型限位。

## 第二轮：纳入固定偏置下的控制可执行范围

`rl/control_feasible_path.py`仅在同一规划中进一步相交控制范围：

`ctrl_min + 1e-8 ≤ initial_ctrl + joint_delta ≤ ctrl_max - 1e-8`。

这保证所采用“初始ctrl-qjoint固定偏置”控制器的节点目标合法；
线性插值保持区间合法。并不保证力矩分配正确或动态跟踪成功。
第二轮仍4候选、同预算、每分支一次执行，非第一轮无限续跑；全部负结果保留。
两轮合计8条候选规划及两次保持基线，无参数随机搜索。

报告：`output/rl/control_feasible_path/2026-10-19_19-29-30-266151/report.json`。
第二轮总墙钟时间约2.26秒；四候选几何与控制范围均通过，均实际执行。

4条候选的左脚在实际执行中均始终接地。最好的固定底座先移重分支虽降低承重，
末端仍远高于5N卸载门槛，不能称成功三肢支撑，更不能称爬行。
接触阶段检查通过也不表示按时离地：该检查仅要求指定的支撑肢仍接地，
成功抬脚另要求末1秒≤1N、无接触且净空≥15mm。
可变底座旋转只作用于规划副本，真实底座从未被直接旋转或写入qpos。

## 决策：从几何转向承重控制，不继续扩展IK搜索

后续固定路径控制审计已完成，见 `RL_PATH_CONTROL_AUDIT.md`：参考末端本身不是原生平衡姿态，
仅改ctrl的局部拟合未修复；需要把小幅姿态/支撑间隙与承重一起求解，不能只增强跟踪。

已有几何与合法位置目标的候选，但原生执行没有卸载，说明不能把这些IK轨迹作为成功物理示范。
当前固定PD偏置不随姿态/载荷重分配变化，是待检验的控制假设，而不是已证明的唯一失败原因。
先移重固定底座分支末载荷约`[79.71,84.49,35.76,112.16] N`：
右脚反而减载、右手显著增载，与几何期望不等价。不能只看某个关节追踪误差而忽略全身承重。

后续应固定这一安全候选作为对照，审计期望/实际COM、关节跟踪、可用力矩与接触力分配；
再在模型ctrl/force硬限位下求姿态相关的承重目标或反馈控制。
先用短时保持验证力矩分配，再执行同一移重路径，禁止通过增加IK自由度/延长执行来掩盖控制问题。
在真实持续卸载、抬脚、落脚与身体前移分别通过前，不扩大RL训练或输出成功示范标签。
