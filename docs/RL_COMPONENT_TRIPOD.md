# 左手离地的原生三支撑平衡尝试

## 协议

只有一个种子：新模型已验证四支撑保持的qpos，加上一轮左手卸载裕量解对应的ctrl。
联合求身体姿态、23关节位置和23个位置伺服目标；最多100迭代/60秒，0重启。
左手地面间隙要求2–20mm，其余三肢载荷>5N，保留5mm穿入筛选、95%力矩比例与关节范围。
支撑水平位置相对原种子偏差≤5mm，足底法向变化≤0.03，COM水平偏移≤40mm。
只有原生平衡通过，才执行初始化后的3秒电机保持。

实现：`rl/component_tripod.py`；复核：`rl/check_component_tripod.py`。
报告：`output/rl/component_tripod/2026-10-19_20-37-24-662654/report.json`。
开始求解前已写入协议，没有临时扩大范围或更换种子。

## 结果：未通过，未执行保持

SLSQP在41次迭代、4590次原生评估后报告不等式约束不兼容。
末点并非可接受的三支撑平衡状态：

| 项目 | 末点数值 | 判断 |
| --- | ---: | --- |
| 左手间隙 | 2.412mm | 已离地 |
| 左手载荷 | 0N | 已卸载 |
| 右手/左脚/右脚载荷 | 123.62 / 112.45 / 69.44N | 都超过5N，但不是静态平衡证明 |
| 最深启用接触穿入 | 4.710mm | 在本轮穿入门槛内 |
| 基座线加速度范数 | **0.3413m/s²** | 超过0.01门槛 |
| 最大角/关节加速度 | **55.47rad/s²** | 超过0.1门槛；对应右踝pitch |
| 右手/左脚/右脚水平偏移 | **7.80 / 14.60 / 18.57mm** | 均超过5mm约束 |
| 足底法向最大变化范数 | **约0.0514** | 超过0.03约束 |
| COM水平位移 | 20.62mm | 在40mm范围内 |

这说明候选在几何上实现了左手离地，但其余接触/姿态与原生动力学未同时满足。
不能以“左手0N”或“其余三肢有载荷”称为三支撑保持成功。
本轮没有生成hold轨迹，也没有让机器人从四支撑状态动态进入这个末点。

## 解释边界

- 求解器报告不兼容是局部非线性求解失败，不是全局不可行证明。
- 末点没有触及关节限位或95%力矩筛选上限，不能据此归因于电机扭矩不足。
- 上一轮静态力分配的可行性，与这一轮原生软接触平衡失败可以同时成立。
- 同时跨越左手接触消失、其余接触调整、姿态与控制变化，对局部求解器是不同于线性力分配的问题。
  这只是可能的数值困难，尚未通过对照实验确认为失败原因。
- 5mm支撑位置约束是本次局部协议，不是硬件定律；不能偷偷放宽它把失败改为成功。

## 下一步：拆开可行性，不添加反馈补丁

暂不继续追这个失败末点。下一项应先在**同一组几何约束**下只求一个左手离地的几何初猜，
判断支撑位置/足底姿态约束本身能否一起满足，再单独进入原生平衡求解。
这样能够区分“几何约束已冲突”和“几何可行但软接触/控制平衡未收敛”。
新增尝试必须独立记录固定预算，不覆盖本轮报告、不凭事后调宽范围获得通过。
若终点平衡找到，仍需单独验证四支撑到三支撑的真实电机过渡；终点不是爬行单步。

接触参数敏感性失败、邻接凸包过滤和实物参数未标定等限制继续保留。
