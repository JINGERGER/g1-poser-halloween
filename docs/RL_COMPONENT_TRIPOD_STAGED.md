## 结果

### 几何阶段通过

3次迭代、92次原生前向评估即满足几何条件：

- 左手离地约2.000mm。
- 右手/左脚/右脚间隙约-4.950mm、0mm、-1.192mm。
- 三支撑最大水平偏移约2.669mm，小于原5mm限制。
- 足底法向最大变化约0.00101，小于原0.03限制。
- COM水平变化约0.060mm，小于原40mm限制。

左脚间隙约`2e-13m`属于数值零；几何上接触不等于承担载荷。
右手恰好接近4.95mm规划穿入边界，也不是高裕量初态。
这些结果证明**同一组几何约束存在解**，不证明它是动力学可行或良好的平衡求解初值。

### 原生平衡仍未通过

46次迭代、5232次评估后，SLSQP报告不等式约束不兼容：

| 项目 | 末点数值 | 判断 |
| --- | ---: | --- |
| 左手间隙 | 约2.406mm | 满足离地要求 |
| 基座线加速度 | 0.1209m/s² | 未通过0.01门槛 |
| 最大角/关节加速度 | 29.024rad/s² | 未通过0.1门槛 |
| 最大支撑水平偏移 | 约6.549mm | 未通过5mm约束 |
| 足底法向最大变化 | 约0.03958 | 未通过0.03约束 |

未执行动态保持，未生成hold轨迹。相较上次部分残差变小不是成功依据。

## 当前证据如何解释

- “几何约束本身无法同时满足”已被本次可行几何解否定。
- 仍未找到原生软接触一致的三支撑平衡，不能声称机器人已能抬手保持。
- 两次局部非线性求解失败，不是全局无解证明，也没有证明电机力矩不足。
- 几何初猜位于接触边界，可能给平衡求解带来困难；这只是待验证解释，不当作已确定根因。

## 下一步边界：停止继续搜索这个静态终点

这一轮完成了几何/动力学的区分。不要再通过换初值、加迭代或放宽支撑约束追同一个终点。
后续应从**已验证的四支撑初态**构造有预算的短时原生动力学卸载过渡，
先检查载荷能否安全下降，而不是要求每一帧或一个预定三支撑末态完全静止。

该过渡必须包含状态连续性、控制变化限制、原5mm穿入门槛、非指定接触与其余支撑监测；
禁止用qpos跳变、清零速度、施加外力或直接执行不平衡LP目标来制造卸载。
可以用几何结果作软参考，但不能把它当成功轨迹标签。
具体优化形式和计算预算在执行前另行记录，本轮尚未实现过渡优化或RL训练。

接触敏感性失败、碰撞近似及硬件参数未标定等限制全部保留。
