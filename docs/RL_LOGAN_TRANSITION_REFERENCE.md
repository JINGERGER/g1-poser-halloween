核对日期：2026-10-23。这里只记录视频观察与待验证假设，不代表我们的模型已经完成过渡。

## 可观察内容与边界

1. 约1.2–1.3秒仍处于直立状态。
2. 约1.35–1.6秒快速降低身体，膝部明显向两侧展开，双臂先抬起/展开，腿部姿态和脚的位置发生变化。
3. 约1.65–1.8秒躯干前倾、双臂一起向地面伸出，进入低位支撑；随后继续爬行。
4. 视觉上支持“双臂近同时落地”路线，不支持把它描述成单臂依次慢慢落地。
5. 单目远景不能精确确定两手首次接触时差、接触力、是否短暂腾空、关节速度或重心轨迹。不能用视频宣称落地冲击安全，也不能反推出作者的精确训练算法。

## 对当前方案的影响

- 主路线改为快速协调降身、双臂近同时建立承重、吸收落地动量、接入爬行。近同时是软偏好，不是左右关节严格镜像或同一仿真步接触的硬约束。
- 早先固定双脚的IK失败不能否定此路线。允许足部调整和短暂卸载，不要求整个过渡过程中静态平衡。
- 当前`StandTransitionTask`没有固定脚，但位置目标增量为每20ms最多0.02rad，即目标变化率最多1rad/s；这不是关节实际速度上限。视频提示应审计它是否限制必要的快速屈腿/伸臂，不能凭视觉直接调大。
- 当前每2ms物理检查与最终稳定交接门槛应区分：过程允许有动量，不意味着接受穿模、超限或躯干撞地。交接前仍需验证接住身体，而非只检测手碰到地面。
- 双臂落地之后允许缓冲和姿态整理，不要求第一次触地就已经满足冻结爬行策略的全部接管条件。

## 下一步实验顺序

1. 先审计控制可达性：关节范围、目标变化率、PD/力矩限制，是否覆盖“屈腿展开—前倾落臂”这类协同动作。不要把目标变化率、人为接管门槛误当机器人固有极限。
2. 构造少量不同持续时间的全身关键姿态参考，视频只提供阶段顺序，不能提供可信的三维关节真值。IK仅做几何候选，所有结果必须通过连续动力学执行检验。
3. 从稳定低位支撑向前扩展短程动态落臂课程；允许训练初态课程，但最终验收必须从真实站立连续执行，不能重置到落地状态拼接成功。
4. 对照有参考与无参考探索，固定物理模型和验收条件；统计首次承重时间、双手接触时差、持续承重、冲击/速度、失败类别和最终爬行接管。
5. 先找到一次可信连续站立到爬行轨迹，再扩大训练与扰动测试。小预算PPO失败不等于物理不可行，视频成功也不等于我们的模型已通过验证。

本次仅核对参考和修订实验方向，未修改控制器、放宽物理门槛或启动新训练。
