# 左脚分阶段减载路径

## 固定设计

使用上轮矩阵中初态2的四肢平衡与左脚离地平衡，前者是路径起点参考，后者只作全身姿态方向参考。
不直接把13.18cm高抬脚姿态当作运动目标；本轮最终净空限定为15–25mm。

六个目标阶段：左脚载荷60–70N、35–45N、10–20N、0–5N，然后净空5–10mm、15–25mm（后两阶段载荷≤1N）。
减载阶段左脚净空限制为[-4.5,2]mm，防止优化器跳过地面卸载过程。
其他三肢原生载荷≥10N，优化穿透≤4.5mm，原模型/PD/摩擦/限矩/原生平衡门槛不变。
约束与力矩由MuJoCo 3.8.0原生计算，不再使用独立接触力变量。

每段以上一已通过解为初值，向已知三肢姿态方向作弱引导；限制相邻候选基座水平增量≤4cm、
竖直≤2cm、旋转增量坐标各≤0.15rad、关节各≤0.25rad。
每段最多150迭代/90秒，第一次约束失败就停止，不重启、不加中间点、不追加迭代。
因此这是有界准静态路径尝试，不是完整轨迹优化或动态反馈控制器。

## 原状态验收

连续重放从原真实带载qpos/qvel/ctrl开始，先用4秒接到已验证四肢参考，之后每个已通过阶段4秒。
阶段内电机目标3秒平滑变化，剩余时间保持；首段额外等待0.5秒。
全过程只写ctrl，限制每20ms变化≤0.01rad，不强写位姿、不注入外力、不重置阶段状态。
每段最后0.2秒的所有采样必须满足该段载荷/间隙与其他三肢承重门槛，否则停止，不延长等待。
穿透>5mm、非支撑部位载荷>1N或基座高度越界立即停止；保留滑移及力矩限幅验收。

首个数学阶段失败时仍重放可用前缀（可能只有四肢起点），但不能把前缀通过记为完整抬脚。
完整通过也只意味着一次原状态卸载/抬起，不含落地、身体推进或连续爬行。
保留旧实验源码和模型，不追加RL训练。

## 已完成的路径尝试

精确等式版报告 `output/rl/staged_transfer/2026-10-19_17-35-06-231265/report.json`：第一阶段150迭代后仍约85.21N，停止。
起点中心差分检查在1e-6、1e-5、1e-4三个步长下，29行加速度等式的相对数值秩均约26；
这是局部数值问题的证据，不是路径不存在的证明。

新增独立 `tolerance_transfer.py`，用更严格的内部加速度容差不等式替代精确零加速度等式：
基座分量≤0.005/√3m/s²、其余≤0.05rad/s²；最终仍使用原0.01m/s²、0.1rad/s²物理验收。
模型、载荷阶段与5mm物理门槛未变。内部优化余量与物理验收分开记录。

正式报告：`output/rl/tolerance_transfer/2026-10-19_17-39-40-189597/report.json`。
前两阶段候选通过，第三阶段仍约44.98N、未达到10–20N，按规则停止。
连续原状态重放12秒，实际左脚末端载荷：四肢起点84.99N→第一阶段61.91N→第二阶段46.80N。
第二阶段要求≤45N，因此未通过阶段门槛，未继续卸载/抬脚。
全段最大穿透4.885mm，非支撑载荷0，最大力矩比例0.543，平均承重滑移3.50mm/s；左脚始终接地。
报告的 `safe=false` 是保守地将阶段未完成也纳入拒绝，不能解释成发生穿透超限或跌倒。

原等式版耗时5.06秒；容差版第一次实现验证3.32秒，正式版10.23秒。
第一次容差版误将更严格内部余量的小偏差当作物理拒绝，修正独立判定后重跑；所有旧报告保留。
三次共5个阶段求解、749次迭代，无训练更新；没有隐藏追加到成功的尝试。
正式版已完成来源哈希、约束重算与12秒qpos/qvel的独立物理重放。

这提供了一段真实减载片段，不是完整卸载或爬行。下一步应从它的真实末态接续，
