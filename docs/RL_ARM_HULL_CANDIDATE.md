# 按部件分离的凸包碰撞候选

## 已实现

不覆盖旧快照或应用默认场景。独立候选：
`output/rl/models/component_hulls_v1_12d607bfdb588900/flat.xml`。

实现：`rl/arm_hull_candidate.py`；检查：`rl/check_arm_hull_candidate.py`。
报告：`output/rl/arm_hull_candidate/2026-10-19_20-19-46-300867/report.json`。

- 上臂：使用对应可视mesh的凸包，替换原胶囊。
- 肘部：在肘部body增加独立mesh凸包，不再依赖腕部胶囊承担覆盖。
- 打印壳体：将配准后的3MF顶点求凸包，生成独立OBJ；不包含完整forearm STL中的球体。
- 手球：保留半径20mm、局部球心180mm版本。
- 移除原上臂/腕部两条显式碰撞排除，不增加新的排除。
- 保留MuJoCo默认邻接body过滤，但额外直接检查上臂/肘部、肘部/壳体、上臂/壳体距离。
- 设置不从geom推导惯量，验证原质量、惯量、关节、电机等数值不变。默认场景未切换。

资产自包含，所有mesh带哈希；重复生成必须完全一致，否则拒绝覆盖。
凸包为保守外包：会填实孔洞和凹槽，不是精确打印实体或实物标定模型。

## 固定回归结果

| 检查 | 结果 |
| --- | --- |
| 原定42个局部姿态 | 0个姿态触发超过1mm的启用自碰撞 |
| 23关节×5全限位样本 | 14个姿态触发超过1mm的启用自碰撞 |
| 直接检查肘部/打印壳体 | 两侧间距约2.200mm |
| 直接检查上臂/肘部凸包 | 重叠约34.75–36.58mm |
| 上臂/壳体直接距离 | 部分样本返回0，其余可达约67.62mm；不宣称严格正间隙 |

全限位扫描包括腿部、上臂/躯干、肘部/躯干和脚/上臂碰撞，不能将关节独立限位直接作为可执行工作区。
“0个启用自碰撞”不等于实体完全不重叠：上臂/肘部是邻接关节，默认过滤仍存在。
该处凸包重叠可能包含关节安装凹槽被填实的贡献，未证明实物干涉，也未证明全部重叠都是假碰撞。
直接距离返回0的样本只按0记录，不把它们包装成安全裕量。

相较旧模型，打印壳体与肘部已有独立、可追溯表示；但邻接关节外形和安装孔洞仍是模型假设。
因此当前资格是**局部初态构造的诊断候选**，不是已验证实物模型或训练默认模型。

## 下一步：有边界地进入初态构造

不再追加全局几何搜索。用该候选从原定旧名义姿态及旧平衡姿态两个种子，
求解身体/关节位置，使四个指定支撑接触，同时检查关节限位、非支撑地面接触及启用自碰撞。
不得只降低机身、扩大球体或恢复上臂/壳体排除来获得接触。

几何初态找到后再求带载平衡，最后用真实电机输入做保持重放；
初始化求解中允许设置qpos，但重放过程中不得直接写qpos或清零速度来伪造稳定。
邻接关节过滤及凸包凹槽假设继续列在结果中，不把该模型内承重等同硬件可行性。
若固定预算内失败，报告接触/碰撞/限位约束，不能无限增加控制器补丁。

本轮没有执行动态rollout或构造新带载reset。
