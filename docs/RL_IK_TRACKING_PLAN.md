# IK 软参考 + 物理 RL（v1，2026-10-16）

实现与验证更新：2026-10-19。训练结果以文末实测记录为准，方案存在不等于爬行成功。

## 决策

不再要求先手工完成整个物理步态。IK 只提供动作方向，RL 可以通过全身残差偏离它；
IK 几何可达不等于专家动作可执行。独立任务 `G1IKTracking23`，不修改旧任务、策略、模型参数或 UniLab。

## 冻结的首轮方案

- 起点：两个已验证支撑策略的 10 秒真实承重 qpos/qvel 和带载 ctrl；不从摆腿帧零速初始化。
  首轮只随机选择两种承重状态并作整体水平平移，承认起点多样性有限，不冒充抗扰动验证。
- IK：沿用本仓库顺序摆腿思想，但按当前承重姿态重新生成 128 帧周期参考。
  周期 4 秒、指令速度 0.03 m/s、先用 2 cm site 抬升；8 cm 保留为后续课程，不作为首轮硬约束。
  四肢相位偏移 [0, .5, .75, .25]、摆动占 25%；平滑周期曲线，不直接循环不闭合的参考动画。
- 启动：保持带载基准 1 秒，再用 1 秒平滑提高相位速度。不固定基座，不施加托举外力。
- 动作：带载 ctrl + IK 关节偏移 + 全身 23 关节残差，残差幅度 ±0.5 rad。
  实际目标遵守原 ctrl 限值和真实动力学。不是只允许摆动腿作小修正。
- 观测：关节状态、重力、局部速度、接触、上一步残差、时间/相位、带载 ctrl，以及当前和未来 .1/.3 秒参考。
  首轮用单一 178 维 actor/critic 输入，不复用旧 85/75/81 维权重；不加入相位速度动作，先减少自由度。
- 奖励：软姿态/脚端相位引导 + 真实速度跟踪，乘以姿态、限矩和接触滑移质量项。
  各项有界且总 reward 非负，物理失败步 reward=0；失败真正 terminated，20 秒超时为 truncated。
  因而不再能仅通过提前终止“省掉负的后续奖励”。不声称消除了所有局部最优或价值估计误差。
  无负的持续成本、无任意巨大的终止罚项，超时价值按 runner 原有 final_observation bootstrap。
- 首轮不加随机摩擦/质量、对称增强、坡地、楼梯或恢复旧 checkpoint。

## 执行顺序与预算

1. 生成内容寻址的独立资产，记录模型/承重源/参考哈希；检查 IK 误差、限位、周期接缝、导数、碰撞。
   对连续插值作额外采样。存在明显几何缺陷则停止，不以动力学必须成功为生成条件。
2. 接口验证：零残差起点、局部重置隔离、真实 PD 力矩、原生步进对照、终止与超时、非负回报反例。
3. 两个 seed 各 10 iteration ×32 env×24 steps，合计 15,360 transitions，仅验证学习链路。
4. 上述通过后才能做两个 seed 各 400 iteration（307,200 transitions），正式小预算合计 614,400。
   从头开始，统一配置；只评估最终权重。默认入口为 smoke，screen 必须显式指定，不能自动扩大预算。
5. 物理评估：100 个固定首回合、20 秒、评估 seed=1001，两种承重状态配对；同时提供保持支撑目标、
   零残差 IK 两个对照。另用少量回合可作诊断，但不得称为正式通过。
   检查实际离地—落地、末端负载、滑移、非末端承重、穿透、前进、力矩和存活，而不是只看 reward/姿态误差。
   沿用原无相位事件判据（15 mm 净空、60 ms 腾空/落地确认，每肢至少两个完整事件）。
   指令 0.03 m/s、20 秒净前进至少 0.3 m；其他物理门槛不为本实验放宽。

## 停止规则与解释

非有限值、原生重放不一致、模型/数据哈希变化、优化器跳过更新即停止。
如果两 seed 都只支撑或滑动，停止追加预算，分析参考与物理目标的冲突，不继续盲调权重。
两 seed 均通过后才安排新起点/扰动测试和更高抬脚课程，最后才坡地、上下楼梯。
参考动作允许不完全物理一致，但不允许把强写姿态、虚构接触或动作裁剪当成学习成功。

### 可以确定什么

1. **没有证据支持“seed1 主要靠抵消周期 IK 而站住”。** 对每回合 2–20s 的逐关节信号去时间均值，
   残差对参考的反向投影系数均值仅 0.0023；参考加残差的交流幅值比为 1.014。
   这是去掉静态姿态偏置后的描述性指标，不代表各关节都正确跟踪，更不代表真实抬脚。
   该窗口四肢端点接触传感器始终为真，与原生评估零完整周期一致。
2. **seed2 不是单纯的确定性评估失配。** 两种执行方式都失败，100/100 终止均有禁止部位接触，
   无高度/姿态阈值触发；首回合为右小腿接触。均值策略在参考启动前就失败。
   原训练最后三轮的 episode/length 滑窗日志约 38–39 个控制步，即 0.76–0.78s，
   说明训练期本身已退化，不能用“没有 NaN/回滚”称其学习健康。
3. **探索对执行质量的破坏很明显，但尚不能认定是唯一根因。** seed1 最终标准差约 0.310，
   乘动作比例后，限幅前单关节目标噪声约 0.155rad；每 20ms 重新采样。
   同一权重从均值变为采样，平均回报从 5.320 降为 0.133；2–20s 质量项均值从 0.438 降为 0.0367。
   这是最终固定策略的对照，不是训练全过程重放，也不是硬件安全结论。
4. **奖励存在鼓励不动的风险。** 保持目标比零残差 IK、两份策略都获得更高回报。
   保持目标在 2–20s 的接触项仍为 0.75、离地项约 0.843、速度项约 0.364。
   三条支撑肢匹配及低速误差容忍让不抬脚仍得分；但没有成功爬行样本可比较，不能断言全局最优是站立。
5. 优化器也不能完全排除：两 seed 第一轮平均 KL 约 0.443/0.381，明显高于配置目标 0.01。
   adaptive LR 调整并不等于硬 KL 停止；不能因此直接认定 PPO 实现有错，也不能只凭末轮 KL 正常忽略它。
