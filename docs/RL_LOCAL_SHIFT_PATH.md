# 小幅移重路径：首轮几何门槛与回放

## 实现与固定预算

实现 `rl/local_shift_path.py`，从此前真实初态出发，使用几何审计给出的质心水平偏移
`[+22.9235, -23.8764] mm`，不再追踪远端静态三肢姿态。

- 三分支：保持、前3秒移重后2秒抬脚、5秒联合移重抬脚；最后1秒保持，总预算各6秒。
- 每条几何候选10节点，每节点最多100次残差评估，解析雅可比，无重启；失败立即停止该路径。
- 变量为底座平移与23关节角；底座旋转固定，关节范围与相对初态±0.5rad范围同时限制。
- 约束任务为四肢site位置与质心xy，保留小姿态正则；检查site/质心误差≤1mm、
  穿透≤5mm、非支撑几何穿透≤1mm、其余三肢接地，末左脚净空至少15mm。
- 左脚site上移22mm是为获得约20mm几何净空的近似目标，实际验收依据几何体间距离，不能混为一谈。
- 路径全部节点通过才允许原生回放；实时仅修改电机目标，保留初始速度，不施加外力。
- 回放以初始`ctrl-qjoint`为固定PD承重偏置，位置目标变化率≤0.01rad/20ms。
  这是近似偏置，不是逆动力学求出的正确承重力矩；候选回放若失败不能直接归咎物理不可行。
- 新路径不沿用此前人为手部载荷方向限制；不是上一轮载荷目标的单变量对照。

## 发现的表示问题

后续右脚姿态约束对照已完成，见 `RL_CONTACT_POSE_PATH.md`。
右脚离地被抑制，但左脚穿透/路径误差仍使两候选失败；需要统一接触阶段约束，而非继续逐点修补IK。

**固定支撑site位置不等于固定支撑接触面。**
右脚旋转自由度未受约束，点坐标准确仍可能导致接触几何离地。
这是路径优化中缺少接触姿态/间隙约束的直接表现，不是执行器支撑能力结论。
本轮接触检查成功阻止不合格IK姿态进入电机回放，没有放宽接地阈值或以site替代实际接触。

下一步应补全接触表示：右脚约束接触姿态与实际地面间隙，手掌按球形碰撞几何处理；
再以相同节点/求解预算检查同两条路径。不能只增加正则权重期待接触自行保持。
如果补全几何约束仍失败，才考虑固定底座旋转等假设是否限制了可达性，且应独立对照。
只有几何通过后才检验PD偏置、动态载荷分配及力矩可行性，不能把这些层次混成一次盲调。
