# 近端接管PPO小实验

## 任务与预算

使用当前CPU PyTorch/MuJoCo环境，不依赖UniLab训练器，不改变爬行权重。
过渡动作是23维原始高斯动作，经tanh后乘0.12rad，叠加到名义爬行初态的关节目标。
先用原生位置PD执行20个控制步（0.4秒），然后在同一MjModel/MjData上切换到冻结爬行控制器运行2秒。
两阶段每个2ms物理子步检查穿透、自碰撞、非支撑触地、限力、关节限位和基座高度。
接管成功还要求2秒内前移≥6cm且存在至少两个相邻合格对角周期。不是仅看姿态或是否摔倒。

固定预算：8次PPO更新×256个过渡控制步=2048步；每更新4轮、64样本小批，学习率3e-4，
gamma=.99、GAE=.95、clip=.2、梯度范数截断.5。训练种子7，保存最终权重，不按评估结果挑checkpoint。
训练初态32个，种子0–31；评估初态8个，种子1000–1007，与训练严格分开。
失败奖励−5，接管成功+20；每个过渡步附加很小的目标姿态接近/动作平滑奖励。
PPO使用原始高斯采样动作的概率，tanh作为固定环境变换，不把截断后动作代回高斯计算概率。
当前记录交接目标/力矩跳变，但尚无单独跳变优化项，不声称已解决平滑接管。

近端初态为名义爬姿加3–15mm机身高度、各关节±.01rad、基座线速度±.1m/s和角速度±.15rad/s。
每个候选必须通过初始化物理筛选；最多50个候选，否则失败，不无限重采样。
初态不代表来自实际站立路径，训练结果不代表完整站立到爬行。

```bash
uv run --extra crawl --python 3.13 python -B rl/check_near_handoff_task.py
uv run --extra crawl --python 3.13 python -B rl/train_near_handoff.py
```

报告：`output/rl/near_handoff_training/2026-10-23_12-17-21-990640/report.json`。
同目录`interpretation.json`基于原报告哈希记录对照解释，`final.pt`是试验权重，不替换现有运行入口。
全套初态生成、三轮评估和2048步训练耗时约20.7秒（本次机器/配置实测，不是一般训练耗时保证）。

| 未训练适配器：固定名义目标保持0.4秒后交接 | 8/8 |
| 最终PPO适配器 | 8/8 |

直接接管的种子1004未满足“相邻合格周期”，并非物理门槛失败：已前移约0.796m，但两个合格周期不相邻。
这只是短评估窗中的一例差异，不能宣称直接接管不稳定。
PPO实际更新完成、参数L2变化约3.379，梯度和损失有限；102个完成的训练episode中101个成功。
关键结论是：**没有观察到优于未训练固定保持的学习收益**。不能把7/8到8/8归功于PPO。
不追加同分布训练预算，不把这8个案例包装成泛化成功率，不升级为生产策略。

评估轨迹均保存每个物理子步状态/控制/增益阶段，并逐步重放核对至1e-10。
测试覆盖GAE终止掩码、观测/动作维数、非法动作不改状态、同实例连续物理和控制重放。
新增逐子步观察接口后，原10秒爬行回归仍逐值相同。
首轮后仅补充每个终端门槛与相对固定保持的报告字段，未因评估结果调奖励或续训。

## 下一阶段：手接地前的短任务

保留相同控制预算、动作空间和成功条件，将初态改为单手或双手离地。
通过局部手臂Jacobian移动手球，基座和腿部坐标保持名义爬姿，不通过抬高整个机器人制造自由落体。
目标手球间隙预先限定为1–3cm；左右手/双手三种模式按种子分配。
检查目标间隙、非目标脚位、碰撞和初始物理门槛，不把IK姿态当作动态可达性证明。
仍保留直接接管、固定保持和最终PPO三组相同初态对照。该阶段只检验落手与接管，不是站立启动。

## 手接地前阶段结果（2026-10-23）

```bash
uv run --extra crawl --python 3.13 python -B rl/train_near_handoff.py --stage hands
```

报告：`output/rl/hand_contact_training/2026-10-23_13-30-57-016782/report.json`。
运行前明确停止规则：若直接接管与未训练固定保持均8/8通过，不执行额外PPO更新。
这条规则用于避免在已达本组上限的任务上增加训练，不是统计意义的全局成功证明。

结果：直接接管8/8、固定名义目标保持0.4秒后接管8/8，触发停止规则；
本阶段没有训练更新、没有产生新的策略权重，也不存在“训练后提高成功率”的结论。
所有评估均在同一8个初态上执行，每个物理子步记录、验收、重放核对。
初态三种模式为左手、右手、双手离地，手间隙1–3cm，机身和腿部qpos不变，
初始水平速度±0.05m/s，其余速度为零；测试检查脚位与基座未被初态生成器移动。
局部IK仅用于生成初态，没有在运行期间改写状态。它不证明这些初态能从站立动态到达。

## 综合决策：停止训练近端修正器

近端PPO未超过固定保持；手接地前的小范围状态已由冻结爬行控制器直接接住。
因此不再为这两档任务追加预算或扩大网络，也不把试验权重部署到默认运行入口。
保留固定保持作为简单对照，接管继续使用冻结爬行控制器。

后续独立过渡任务应把预算放在真正未解决的区间：

- 从已验证站姿开始，动态降低机身并建立手部支撑；允许改变脚位，避免固定双脚IK的碰撞路线。
- 过渡动作空间必须能覆盖较大姿态变化，不能沿用近端±0.12rad残差去假装完成全部动作。
- 已验证2.5cm受控降低可作为早期参考片段，但不是通向爬行的完整示范。
- 终端奖励仍由连续物理接管决定，站立到近端的状态不能通过重置/瞬移获得。
- 在完整路径建立前，不再把小范围端点验收重复解释成新的整体进展。
